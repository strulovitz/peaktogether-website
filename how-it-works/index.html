How It Works

Peak Together is a little arcade of free games for two curious minds. Each game turns one of the hardest problems in science or math into something you can play — side by side, on one screen.

1. Get the game

Every game is open-source and free. Head to The Arcade, pick a game, and download it. No account, no payment, ever.

2. Run it — no Python, no terminal

Our games run on Windows with a single double-click. Nothing to install, nothing technical to learn:

  1. Download the game's Windows .zip.
  2. Right-click it → Extract All…
  3. Open the extracted folder.
  4. Double-click the game's .exe file — and you're flying. 🚀

No Python, no terminal, no installer, no admin needed. To uninstall, just delete the folder.

3. Controls

You can play with keyboard + mouse, or plug in a flight joystick and a gamepad for the full two-player experience. One person flies, the other thinks — and you have to talk to each other to win.

Playing solo?

That works too! You can fly and think on your own — it's just more fun (and easier) with someone you love beside you. 💕
