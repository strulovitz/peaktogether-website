TITLE { Maxwell's Equations — Faraday & Ampere }

STAINS {
  electric = 0.85 0.12 0.12     # red
  magnetic = 0.12 0.30 0.85     # blue
  coupling = 0.55 0.10 0.65     # purple  (electric + magnetic)
}

ROBOT: 3
  NAME { Faraday }

  EXPLAIN_MATHEMATICIAN {
    Faraday's law is
    \stain{coupling}{$\displaystyle \nabla \times \stain{electric}{$\mathbf{E}$}
    = -\frac{\partial \stain{magnetic}{$\mathbf{B}$}}{\partial t}$}.
    The curl on the left, \thread{curl}{$\nabla \times \mathbf{E}$}, expands to
    \thread{curl}{$\left(\partial_y E_z - \partial_z E_y,\ \partial_z E_x - \partial_x E_z,\ \partial_x E_y - \partial_y E_x\right)$}.
  }

  EXPLAIN_PHYSICIST {
    A changing \stain{magnetic}{magnetic field} pushes on charges and creates
    a swirling \stain{electric}{electric field}. The minus sign
    (\thread{lenz}{$-\,\partial_t \mathbf{B}$}, i.e. \thread{lenz}{the induced effect opposes the change})
    is why a moving magnet through a coil lights a bulb.
  }

  EXPLAIN_BIOLOGIST {
    Think of \stain{magnetic}{the magnetic field} as a river current changing speed.
    The water around it starts spinning --- that spin is
    \stain{electric}{the electric field} it induces.
  }

  EXPLAIN_ENGINEER {
    This is the generator. Spin a magnet
    (\stain{magnetic}{changing $\mathbf{B}$}) and you get voltage
    (\stain{electric}{$\mathbf{E}$ around the loop}): power from motion.
  }

ROBOT: 4
  NAME { Ampere }

  EXPLAIN_MATHEMATICIAN {
    Ampere--Maxwell:
    \stain{coupling}{$\displaystyle \nabla \times \stain{magnetic}{$\mathbf{B}$}
    = \mu_0\mathbf{J} + \mu_0\varepsilon_0 \frac{\partial \stain{electric}{$\mathbf{E}$}}{\partial t}$}.
    Note the symmetry with Faraday: now \stain{magnetic}{$\mathbf{B}$} curls because
    \stain{electric}{$\mathbf{E}$} changes.
  }

  EXPLAIN_PHYSICIST {
    A changing \stain{electric}{electric field} creates a
    \stain{magnetic}{magnetic field} --- the mirror of Faraday. Maxwell's added
    term \thread{disp}{$\mu_0\varepsilon_0\,\partial_t \mathbf{E}$} is the
    \thread{disp}{displacement current} that lets the two fields trade energy and
    fly off as light.
  }

  EXPLAIN_BIOLOGIST {
    Just as before but reversed: now \stain{electric}{the electric field}
    changing makes \stain{magnetic}{the magnetic field} swirl around it.
  }

  EXPLAIN_ENGINEER {
    This is the antenna and the transformer: push current, get
    \stain{magnetic}{magnetic field}; the changing
    \stain{electric}{electric field} between capacitor plates keeps the circuit
    "complete" even through empty space.
  }
