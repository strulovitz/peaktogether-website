ROBOT {
    number 1
    NAME { Gauss's Law (Electric) }
    BRIEFING_HINT { This sentinel guards charge. It answers only to the law that ties electric flux to the charge enclosed. }
    PROBLEM { Gauss's law (electric) states that the net electric flux through any closed surface is proportional to the electric charge enclosed within that surface. In differential form, the divergence of the electric field equals the charge density divided by the permittivity of free space. }

    EXPLAIN_WHAT { This law relates the spreading-out of the electric field to where electric charge sits. Wherever charge piles up, field lines are born or buried. }
    EXPLAIN_WHY  { It lets an engineer find the electric field from a known charge distribution, by tallying the charge sealed inside a chosen surface. }
    EXPLAIN_HOW  { Pick a closed surface, add up the charge inside, and divide by the permittivity. The flux out the surface follows. For a small box of charge [[ $Q = 4.0\,\mathrm{nC}$ | 4.0 ]] with permittivity [[ $\varepsilon_0 = 8.85\times10^{-12}\,\mathrm{F/m}$ | 8.85e-12 ]], the enclosed flux is [[ $\Phi_E = Q/\varepsilon_0 \approx 452\,\mathrm{V\,m}$ | 452 ]]. }
    EXPLAIN_SO   { So a single resting charge has a field that points straight outward, falling off with distance — no magnetism needed to describe it. }

    SEGMENTS {
        \nabla \cdot \mathbf{E} = \dfrac{\rho}{\varepsilon_0} | red
    }

    EYE { red }
    VULNERABLE_TO { gauss_e }

    FIZZLE gauss_m {
        Gentle miss :-) That was the magnetic Gauss law — it says magnetism has no sources, so it can't account for the enclosed charge this sentinel is built from. You want the ELECTRIC flux law instead.
    }
    FIZZLE faraday {
        Soft fizzle. Faraday's law is about a CHANGING magnetic field stirring up electric fields in loops. This robot is a static-charge problem — no change, no loops. Reach for the electric flux law (Gauss, electric).
    }
    FIZZLE ampere {
        That bounced off harmlessly. Ampere's law links a magnetic field to the current that makes it. There's no current here — only resting charge. Try the electric Gauss law.
    }
    FIZZLE maxwell {
        Pretty, but it fizzled. Maxwell's correction adds a changing-E term to magnetism — overkill for a still charge with no fields changing. The plain electric flux law is the key.
    }
}

ROBOT {
    number 2
    NAME { Gauss's Law (Magnetic) }
    BRIEFING_HINT { This sentinel insists there are no magnetic charges. Answer it with the law that says magnetic field lines never end. }
    PROBLEM { Gauss's law for magnetism states that the net magnetic flux through any closed surface is zero, expressing the experimental absence of magnetic monopoles. In differential form, the divergence of the magnetic field vanishes everywhere. }

    EXPLAIN_WHAT { This law says magnetic field lines have no beginnings and no endings — they always close into loops. There is no such thing as an isolated north pole. }
    EXPLAIN_WHY  { It guarantees that whatever magnetic flux enters a closed surface also leaves it, which constrains every magnetic-field calculation. }
    EXPLAIN_HOW  { Sum the magnetic flux over a closed surface and it must come to zero. For a bar magnet inside a sphere, flux out the north side [[ $\Phi_{out} = +1.2\,\mathrm{mWb}$ | 1.2 ]] is exactly cancelled by flux in the south side [[ $\Phi_{in} = -1.2\,\mathrm{mWb}$ | -1.2 ]], net [[ $\Phi_B = 0\,\mathrm{Wb}$ | 0 ]]. }
    EXPLAIN_SO   { So you can never trap a lone magnetic pole — cut a magnet in half and each piece grows its own pair of poles. }

    SEGMENTS {
        \nabla \cdot \mathbf{B} = 0 | blue
    }

    EYE { blue }
    VULNERABLE_TO { gauss_m }

    FIZZLE gauss_e {
        Gentle miss :-) That was the ELECTRIC flux law, which ties flux to enclosed charge. But magnetism has no charges — this sentinel needs the law whose flux is always zero. Use the magnetic Gauss law.
    }
    FIZZLE faraday {
        Soft fizzle. Faraday's law is about changing magnetic fields inducing electric ones. This robot is the static statement that magnetic flux closes on itself. Try Gauss's law for magnetism.
    }
    FIZZLE ampere {
        That fizzled harmlessly. Ampere's law connects magnetic fields to currents — it's about the SOURCE of B, not about flux summing to zero. Reach for the magnetic Gauss law.
    }
    FIZZLE maxwell {
        No harm done. Maxwell's correction patches Ampere's law with a changing-E term. This robot just states "no magnetic monopoles." Use the magnetic flux law (Gauss, magnetic).
    }
}

ROBOT {
    number 3
    NAME { Faraday's Law }
    BRIEFING_HINT { This sentinel couples the two fields: a changing magnet stirs an electric whirl. Answer it with the induction law. }
    PROBLEM { Faraday's law of induction states that the curl of the electric field equals the negative time rate of change of the magnetic field. A time-varying magnetic flux through a loop induces a circulating electromotive force around that loop. }

    EXPLAIN_WHAT { This law says a magnetic field that changes in time wraps an electric field around it. It is the rule behind every generator and transformer. }
    EXPLAIN_WHY  { It lets an engineer turn motion or a switching magnet into voltage, predicting the induced EMF from how fast the magnetic flux changes. }
    EXPLAIN_HOW  { Take the rate of change of magnetic flux and negate it to get the loop EMF. With flux falling at [[ $d\Phi_B/dt = -0.30\,\mathrm{Wb/s}$ | -0.30 ]] through [[ $N = 200$ | 200 ]] turns, the induced EMF is [[ $\mathcal{E} = -N\,d\Phi_B/dt = 60\,\mathrm{V}$ | 60 ]]. }
    EXPLAIN_SO   { So you cannot treat E and B separately here — wiggle the magnet and electricity appears. This is where the two fields genuinely couple. }

    SEGMENTS {
        \nabla \times \mathbf{E} = -\dfrac{\partial \mathbf{B}}{\partial t} | purple
    }

    EYE { purple }
    VULNERABLE_TO { faraday }

    FIZZLE gauss_e {
        Gentle miss :-) The electric flux law handles resting charge. But this sentinel is about a CHANGING magnetic field inducing electricity — both fields are in play. You want Faraday's induction law.
    }
    FIZZLE gauss_m {
        Soft fizzle. The magnetic flux law is a static "no monopoles" rule. This robot is dynamic: a changing B making a curling E. Reach for Faraday's law.
    }
    FIZZLE ampere {
        That bounced harmlessly. Ampere's law makes B from current. Faraday's is the mirror twin — a changing B making E. Notice the coupling of both fields here, and use Faraday's law.
    }
    FIZZLE maxwell {
        Close cousins, but it fizzled! Maxwell's correction adds changing-E to Ampere's (magnetism) side. This robot is the induction side — changing-B making E. Use Faraday's law.
    }
}

ROBOT {
    number 4
    NAME { Ampere's Law }
    BRIEFING_HINT { This sentinel guards steady current. Answer it with the law that builds a magnetic field from the current flowing through. }
    PROBLEM { Ampere's law (in its original, magnetostatic form) states that the curl of the magnetic field equals the permeability of free space times the electric current density. The circulation of the magnetic field around a closed loop is set by the current threading that loop. }

    EXPLAIN_WHAT { This law says an electric current wraps a magnetic field around itself. Run current up a wire and a circle of magnetism surrounds it. }
    EXPLAIN_WHY  { It lets an engineer compute the magnetic field of wires, coils, and solenoids directly from the current they carry. }
    EXPLAIN_HOW  { Add up the magnetic field around a closed loop; it equals permeability times enclosed current. Around a wire carrying [[ $I = 3.0\,\mathrm{A}$ | 3.0 ]] at radius [[ $r = 5.0\,\mathrm{mm}$ | 5.0e-3 ]], the field is [[ $B = \mu_0 I / (2\pi r) \approx 1.2\times10^{-4}\,\mathrm{T}$ | 1.2e-4 ]]. }
    EXPLAIN_SO   { So a steady current alone is enough to make magnetism — no changing fields required in this static picture. }

    SEGMENTS {
        \nabla \times \mathbf{B} = \mu_0 \mathbf{J} | blue
    }

    EYE { blue }
    VULNERABLE_TO { ampere }

    FIZZLE gauss_e {
        Gentle miss :-) The electric flux law is about enclosed charge, not flowing current. This sentinel makes magnetism FROM current. Reach for Ampere's law.
    }
    FIZZLE gauss_m {
        Soft fizzle. The magnetic flux law says B-lines close up — true, but it doesn't tell you the SOURCE of B. The source here is current. Use Ampere's law.
    }
    FIZZLE faraday {
        That fizzled gently. Faraday's law makes E from a changing B. This robot is the reverse and the steady case: current making B. Try Ampere's law.
    }
    FIZZLE maxwell {
        So near! It fizzled though. Maxwell's correction is Ampere's law PLUS a changing-E term. This sentinel is the plain, steady-current Ampere's law — no changing fields. Use Ampere's law.
    }
}

ROBOT {
    number 5
    NAME { Maxwell's Correction }
    BRIEFING_HINT { The final sentinel demands the missing piece: a changing electric field acts like a current. Answer with Maxwell's correction. }
    PROBLEM { Maxwell's correction (the Ampere–Maxwell law) augments Ampere's law with the displacement-current term: the curl of the magnetic field equals the permeability times the sum of the conduction current density and the permittivity times the time rate of change of the electric field. This term completes the equations and permits electromagnetic waves. }

    EXPLAIN_WHAT { This law adds a new source of magnetism: a CHANGING electric field, even with no real current, behaves like a current and creates a magnetic field. }
    EXPLAIN_WHY  { It closes the gap in Ampere's law (e.g. between capacitor plates where no charge crosses) and predicts light itself as a self-sustaining E–B wave. }
    EXPLAIN_HOW  { Add the displacement current to the real current. For a capacitor with E rising at [[ $dE/dt = 5.0\times10^{9}\,\mathrm{V/(m\,s)}$ | 5.0e9 ]] and permittivity [[ $\varepsilon_0 = 8.85\times10^{-12}\,\mathrm{F/m}$ | 8.85e-12 ]], the displacement current density is [[ $J_d = \varepsilon_0\,dE/dt \approx 4.4\times10^{-2}\,\mathrm{A/m^2}$ | 4.4e-2 ]]. }
    EXPLAIN_SO   { So a changing E feeds B and a changing B feeds E — the two fields hand energy back and forth and sail off together as light. This is the deepest coupling of the two fields. }

    SEGMENTS {
        \nabla \times \mathbf{B} = \mu_0 \mathbf{J} + \mu_0 \varepsilon_0 \dfrac{\partial \mathbf{E}}{\partial t} | purple
    }

    EYE { purple }
    VULNERABLE_TO { maxwell }

    FIZZLE gauss_e {
        Gentle miss :-) The electric flux law handles resting charge only. This final sentinel is the dynamic coupling where a changing E makes B. Use Maxwell's correction.
    }
    FIZZLE gauss_m {
        Soft fizzle. The magnetic flux law is the static "no monopoles" rule. This robot adds the displacement-current term that couples the fields. Reach for Maxwell's correction.
    }
    FIZZLE faraday {
        That fizzled gently. Faraday's law is the OTHER coupling: changing B makes E. This sentinel is the changing-E-makes-B side. Use Maxwell's correction.
    }
    FIZZLE ampere {
        So close! But it fizzled. Plain Ampere's law is missing exactly one piece here — the changing-E (displacement-current) term. Add that piece: use Maxwell's correction.
    }
}
