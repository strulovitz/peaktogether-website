ROBOT: 1
  NAME { Bernhard Riemann }
  EXPLAIN_MATHEMATICIAN { The Riemann zeta function is $\displaystyle \zeta(s)=\stain{the_sum}{$\sum_{n=1}^{\infty}\frac{1}{n^s}$}$, convergent for $\mathrm{Re}(s)>1$. The Basel problem is the single value $s=2$: $\displaystyle \stain{basel_value}{$\zeta(2)=\sum_{n=1}^{\infty}\frac{1}{n^2}$}$. The whole corridor lives inside this one function. }
  EXPLAIN_PHYSICIST { Instead of one fixed sum, allow the exponent to vary: $\zeta(s)=\stain{the_sum}{$\sum 1/n^s$}$. For $s=3$ you add $\thread{t1}{1+\tfrac18+\tfrac1{27}+\cdots}$; for $s=2$ you add $\thread{t1}{1+\tfrac14+\tfrac19+\cdots}$. Basel is precisely the $s=2$ slice, $\stain{basel_value}{$\zeta(2)$}$, and it is finite because $s=2>1$. }
  EXPLAIN_BIOLOGIST { Riemann's zeta function is a machine with one dial, $s$. Set the dial and it adds up $\stain{the_sum}{$1$ over every whole number raised to that power}$. Turn the dial to $2$ and you get the Basel sum, $\stain{basel_value}{$1+\tfrac14+\tfrac19+\cdots$}$ — the one famous question this whole journey is about. }
  EXPLAIN_ENGINEER { Pick the exponent and the machine computes. At $s=3$ the sum is about $\thread{t1}{1.202}$; at $s=2$ the sum $\stain{the_sum}{$\sum 1/n^2$}$ meets the readout: $\zeta(2)=$ [[ $\sum \frac{1}{n^2}$ | 1.6449 ]]. Basel is just one setting of the dial. }

ROBOT: 3
  NAME { Augustin-Louis Cauchy }
  EXPLAIN_MATHEMATICIAN { The integral test (Maclaurin–Cauchy): for $f$ positive and decreasing, $\stain{the_sum}{$\sum_{n=1}^{\infty} f(n)$}$ converges iff $\stain{bounding}{$\int_{1}^{\infty} f(x)\,dx$}$ is finite. With $f(x)=\thread{t3}{1/x^2}$, $\displaystyle \stain{convergence}{$\int_{1}^{\infty}\frac{dx}{x^2}=\Big[-\frac1x\Big]_1^{\infty}=1<\infty$}$, so $\sum 1/n^2$ converges. }
  EXPLAIN_PHYSICIST { Lay the bars $f(n)$ beside the smooth curve $\thread{t3}{f(x)=1/x^2}$. Because the curve decreases, the bars are trapped by the area underneath: $\stain{the_sum}{$\sum f(n)$}$ and $\stain{bounding}{$\int f(x)\,dx$}$ live or die together. Here $\stain{bounding}{$\int_{1}^{\infty}\tfrac{1}{x^2}\,dx = \tfrac{1}{1}=1$}$ is a finite area, so the sum is $\stain{convergence}{\text{finite too}}$. }
  EXPLAIN_BIOLOGIST { Picture each term as a thin rectangle and the smooth curve $\thread{t3}{1/x^2}$ draped over them. The rectangles can never stick out far above a falling curve, so if the area under the curve is finite, the stack of rectangles is finite too. The area here is finite, so the $\stain{convergence}{\text{sum settles down}}$. }
  EXPLAIN_ENGINEER { Compare the sum to an area. The curve $\thread{t3}{1/x^2}$ encloses area [[ $\int_{1}^{\infty}\frac{dx}{x^2}$ | 1.000 ]]. A finite area means a $\stain{convergence}{\text{finite sum}}$: [[ $\sum \frac{1}{n^2}$ | 1.6449 ]] cannot blow up because its area cap is just [[ $1$ | 1.000 ]] plus the first term. }

  NAME { Nicole Oresme }
  EXPLAIN_MATHEMATICIAN { Direct comparison gives a tighter handle: for $n\ge 2$, $\stain{the_sum}{$\frac{1}{n^2}$}<\stain{bounding}{$\frac{1}{n(n-1)}$}$, since $\thread{t4}{n(n-1)}<\thread{t4}{n^2}$.   EXPLAIN_PHYSICIST { We need an upper fence for $\stain{the_sum}{$1/n^2$}$. Compare denominators: $\thread{t4}{n(n-1)}$ is slightly \emph{smaller} than $\thread{t4}{n^2}$, so its reciprocal is slightly \emph{bigger}: $\frac{1}{n^2}<\stain{bounding}{$\frac{1}{n(n-1)}$}$ for every $n\ge 2$. So $\sum 1/n^2$ is bounded above by $1+\stain{bounding}{$\sum_{n=2}^{N}\frac{1}{n(n-1)}$}$, and the bigger series will turn out to be easy. }
  EXPLAIN_BIOLOGIST { To prove a stack of numbers is not too tall, compare each piece to a slightly taller, friendlier piece. Each $\stain{the_sum}{$1/n^2$}$ is a little smaller than $\stain{bounding}{$\frac{1}{n(n-1)}$}$, because $n\times(n-1)$ is a little smaller than $n\times n$. Swap in the friendlier terms and the total can only go up — so if THAT total is tame, ours is too. }
  EXPLAIN_ENGINEER { Take $n=2$: $\stain{the_sum}{$\frac{1}{n^2}$}=$ [[ $\frac{1}{2^2}$ | 0.250 ]] while $\stain{bounding}{$\frac{1}{n(n-1)}$}=$ [[ $\frac{1}{2 \cdot 1}$ | 0.500 ]] — bigger, as promised. ROBOT: 5
  NAME { Evangelista Torricelli }
  EXPLAIN_MATHEMATICIAN { The comparison series telescopes. Partial fractions give $\stain{bounding}{$\frac{1}{n(n-1)}$}=\thread{t5}{\frac{1}{n-1}}-\thread{t5}{\frac{1}{n}}$, so $\displaystyle \sum_{n=2}^{N}\Big(\thread{t5}{\frac{1}{n-1}}-\thread{t5}{\frac{1}{n}}\Big)=\stain{convergence}{$1-\frac{1}{N}$}$, the method of differences collapsing all interior terms. }
  EXPLAIN_PHYSICIST { Split each term: $\stain{bounding}{$\frac{1}{n(n-1)}$}=\thread{t5}{\frac{1}{n-1}}-\thread{t5}{\frac{1}{n}}$. Now write the sum out: $\big(\tfrac11-\tfrac12\big)+\big(\tfrac12-\tfrac13\big)+\big(\tfrac13-\tfrac14\big)+\cdots$. Each $-\tfrac1k$ is cancelled by the next $+\tfrac1k$; only the very ends survive, leaving $\stain{convergence}{$1-\frac{1}{N}$}$. }
  EXPLAIN_BIOLOGIST { Each friendly term secretly equals one fraction \emph{minus} the next: $\thread{t5}{\frac{1}{n-1}}-\thread{t5}{\frac{1}{n}}$. Line them up and they cancel like a collapsing telescope — the inside pieces destroy each other in pairs, and only the first and last survive, leaving $\stain{convergence}{$1-\frac{1}{N}$}$. }
  EXPLAIN_ENGINEER { Watch it collapse with $N=4$: $\big(1-\tfrac12\big)+\big(\tfrac12-\tfrac13\big)+\big(\tfrac13-\tfrac14\big)$. The middles cancel and you are left with [[ $1-\frac{1}{4}$ | 0.750 ]]. As $N$ grows this becomes [[ $1-\frac{1}{N}$ | 1.000 ]]. }

  EXPLAIN_MATHEMATICIAN { Combining the steps: $\displaystyle \stain{the_sum}{$\sum_{n=1}^{N}\frac{1}{n^2}$}<1+\Big(\stain{convergence}{$1-\frac{1}{N}$}\Big)\xrightarrow{N\to\infty}\thread{t6}{2}$. ROBOT: 7
  NAME { Jacob Bernoulli }
  EXPLAIN_MATHEMATICIAN { For every positive even integer, $\displaystyle \stain{basel_value}{$\zeta(2n)=\frac{(2\pi)^{2n}(-1)^{n+1}B_{2n}}{2\,(2n)!}$}$, where $B_{2n}$ is a Bernoulli number.   EXPLAIN_PHYSICIST { The Bernoulli numbers $\thread{t7}{B_2=\tfrac16},\ B_4=-\tfrac1{30},\dots$ are a fixed sequence of rationals.
