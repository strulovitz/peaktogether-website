ROBOT: 1
  NAME { Marc-Antoine Parseval }
  EXPLAIN_MATHEMATICIAN { Parseval's identity equates two energies: $\displaystyle \stain{identity}{$\|f\|^2=\sum_{k=-\infty}^{\infty}|\langle f,e_k\rangle|^2$}$. The whole-function $\stain{norm}{\text{energy}}$ on the left equals the total $\stain{frequency}{\text{spectral energy}}$ on the right. Choosing $f(\vartheta)=\vartheta$ will deliver $\stain{answer}{$\zeta(2)$}$. }
  EXPLAIN_PHYSICIST { A signal carries the same total energy whether you measure it in time or in frequency. Parseval makes this exact: the integral of the square, $\stain{norm}{$\int_0^1 |f|^2$}$, equals the sum of the squared $\stain{frequency}{\text{Fourier amplitudes}}$, $\stain{frequency}{$\sum |\langle f,e_k\rangle|^2$}$. Feed in $f(\vartheta)=\vartheta$ and out falls $\stain{answer}{$\pi^2/6$}$. }
  EXPLAIN_BIOLOGIST { Imagine a sound. You can measure its loudness directly, or you can break it into pure tones and add up the loudness of each tone — and you get the same total. That is $\stain{identity}{\text{Parseval's rule}}$. Apply it to one simple ramp and the circle number $\stain{answer}{$\pi^2/6$}$ drops out. }
  EXPLAIN_ENGINEER { Energy in equals energy out: the time-domain $\stain{norm}{\text{power}}$ [[ $\int_0^1 \lvert f\rvert^2$ | 0.3333 ]] matches the sum of $\stain{frequency}{\text{band powers}}$ [[ $\sum \lvert\langle f,e_k\rangle\rvert^2$ | 0.3333 ]], so they balance -- and for the ramp this rebuilds $\stain{answer}{$\pi^2/6$}$ = [[ $\frac{\pi^2}{6}$ | 1.6449 ]], an exact constant from an endless sum. }

ROBOT: 2
  NAME { Pythagoras }
  EXPLAIN_MATHEMATICIAN { Parseval is the Pythagorean theorem in a Hilbert space: $\stain{norm}{$\|x\|^2$}=\sum_k \stain{frequency}{$|\langle x,e_k\rangle|^2$}$. For orthogonal $\thread{t1}{u}\perp \thread{t2}{v}$, $\thread{t3}{\|u+v\|^2}=\thread{t1}{\|u\|^2}+\thread{t2}{\|v\|^2}$; extended to a complete orthonormal family this is the identity itself. }
  EXPLAIN_PHYSICIST { In the plane, $\thread{t3}{c^2}=\thread{t1}{a^2}+\thread{t2}{b^2}$: the squared length is the sum of squared components along perpendicular axes.   EXPLAIN_BIOLOGIST { Right triangle: the long side squared equals the sum of the two short sides squared. Now picture a shape with infinitely many corners, all at right angles to each other. Its $\stain{norm}{\text{length squared}}$ is still just the sum of all its $\stain{frequency}{\text{squared shadows}}$ on those directions. That is all Parseval says. }
  EXPLAIN_ENGINEER { Pythagoras with numbers: legs $\thread{t1}{a}$ [[ $a$ | 3.000 ]] and $\thread{t2}{b}$ [[ $b$ | 4.000 ]] give hypotenuse $\thread{t3}{\sqrt{a^2+b^2}}$ [[ $\sqrt{a^2+b^2}$ | 5.000 ]]. ROBOT: 3
  NAME { David Hilbert }
  EXPLAIN_MATHEMATICIAN { The arena is $\stain{basis}{$L^2_{\mathrm{per}}(0,1)$}$ with inner product $\stain{norm}{$\langle f,g\rangle=\int_0^1 f(x)\overline{g(x)}\,dx$}$ and norm $\stain{norm}{$\|f\|=\sqrt{\langle f,f\rangle}$}$.   EXPLAIN_PHYSICIST { A Hilbert space is ordinary geometry with infinitely many dimensions: it has lengths and angles through an $\stain{norm}{\text{inner product}}$ $\thread{t1}{\langle f,g\rangle}=\int_0^1 f\overline{g}\,dx$, and the $\stain{norm}{\text{length}}$ is $\thread{t2}{\|f\|}=\sqrt{\thread{t1}{\langle f,f\rangle}}$.   EXPLAIN_BIOLOGIST { Think of arrows in space: you can measure how long an arrow is and the angle between two arrows.   EXPLAIN_ENGINEER { Treat a function like a vector with infinitely many coordinates. ROBOT: 4
  NAME { Joseph Fourier }
  EXPLAIN_MATHEMATICIAN { The complex exponentials $\stain{basis}{$e_k(\vartheta)=e^{2\pi i k\vartheta}$}$ are orthonormal: $\langle e_k,e_j\rangle=\int_0^1 e^{2\pi i(k-j)\vartheta}\,d\vartheta=\delta_{k,j}$.   EXPLAIN_PHYSICIST { Fourier's axes are the pure waves $\stain{basis}{$e_k=e^{2\pi i k\vartheta}$}$, one per integer frequency $k$.   EXPLAIN_BIOLOGIST { Fourier's big idea: any repeating wiggle is a stack of pure, evenly spaced tones. Those tones are the $\stain{basis}{\text{building-block waves}}$, all at right angles to one another. How much of each tone is present is that tone's $\stain{coefficients}{\text{coefficient}}$ — found by overlapping the function with that wave. }
  EXPLAIN_ENGINEER { The basis is the bank of pure tones $\stain{basis}{$e^{2\pi i k\vartheta}$}$ for $k=\dots,-1,0,1,\dots$. They are orthonormal: a wave with itself overlaps to $\stain{basis}{$\langle e_k,e_k\rangle$}$ [[ $\langle e_k,e_k\rangle$ | 1.000 ]] while two different waves overlap to $\langle e_k,e_j\rangle$ [[ $\langle e_k,e_j\rangle$ | 0.000 ]].   NAME { Brook Taylor }
  EXPLAIN_MATHEMATICIAN { For $f(\vartheta)=\vartheta$, integration by parts gives $\displaystyle \stain{coefficients}{$\langle f,e_k\rangle=\int_0^1\vartheta\,e^{-2\pi i k\vartheta}\,d\vartheta=-\frac{1}{2\pi i k}$}$ for $k\neq0$, and $\thread{t1}{\tfrac12}$ for $k=0$.   EXPLAIN_PHYSICIST { Integration by parts, $\int u\,dv=\thread{t1}{uv}-\int v\,du$, turns $\int_0^1\vartheta\,e^{-2\pi i k\vartheta}\,d\vartheta$ into a boundary term minus an easy integral.   EXPLAIN_BIOLOGIST { To overlap the ramp $\vartheta$ with a wave we use a trick that trades a hard integral for an easy one: differentiate the simple part, integrate the wavy part.   EXPLAIN_ENGINEER { Integration by parts is the lever: $\int u\,dv=uv-\int v\,du$.
