TITLE { The Basel Problem — Generalizing to All Even Zeta Values }

STAINS {
  roots          = 0.85 0.12 0.12   # red — the roots -pi^2/k^2 and the source of every pi; primitive feeding the symmetric machinery and the final pi^{2n}
  power_sums      = 0.90 0.78 0.10   # yellow — the power sums p_k = the zeta values themselves; Newton's raw input; shared by the machinery and the generating function
  trig_fn        = 0.12 0.30 0.85   # blue — the analytic function being expanded (sine / cotangent); the object whose coefficients we read
  sym_machinery  = 0.90 0.45 0.10   # orange — elementary symmetric polynomials built from power sums = red(roots) + yellow(power sums)
  generating_fn  = 0.15 0.55 0.20   # green — the cotangent/Bernoulli generating function whose coefficients ARE the zeta values = yellow(power sums) + blue(the function)
  even_zeta       = 0.55 0.10 0.65   # purple — zeta(2n) = rational x pi^{2n}, the synthesis the corridor descends to = red(roots give pi) + blue(the function)

ROBOT: 1
  NAME { Leonhard Euler }
  EXPLAIN_MATHEMATICIAN { Euler's $1734$ trick is not a one-off. Reading \emph{higher} coefficients of $\stain{trig_fn}{$\frac{\sin x}{x}$}$ yields every even zeta value: $\stain{even_zeta}{$\zeta(4)=\frac{\pi^4}{90}$}$, $\stain{even_zeta}{$\zeta(6)=\frac{\pi^6}{945}$}$, and in general $\stain{even_zeta}{$\zeta(2n)=q_n\,\pi^{2n}$}$ for a rational $q_n$. }
  EXPLAIN_PHYSICIST { Basel solved $\stain{power_sums}{$\zeta(2)=\frac{\pi^2}{6}\approx 1.6449$}$ by matching the $x^2$ coefficient. Go further: the $x^4$ coefficient gives $\stain{even_zeta}{$\zeta(4)=\frac{\pi^4}{90}\approx 1.0823$}$, the $x^6$ coefficient gives $\stain{even_zeta}{$\zeta(6)=\frac{\pi^6}{945}\approx 1.0173$}$. Each one is $\stain{even_zeta}{\text{(a fraction)}\times\pi^{2n}}$. }
  EXPLAIN_BIOLOGIST { Euler found $1+\tfrac14+\tfrac19+\cdots=\stain{even_zeta}{$\pi^2/6$}$. The same machine, pushed harder, also adds up the fourth powers, the sixth powers, and so on — and every answer is a plain fraction multiplied by a power of $\stain{roots}{$\pi$}$. }
  EXPLAIN_ENGINEER { One method, many constants. Matching coefficient by coefficient turns the inverse-power sums into exact values: $\stain{even_zeta}{$\zeta(2)=\frac{\pi^2}{6}=1.6449$}$, $\stain{even_zeta}{$\zeta(4)=\frac{\pi^4}{90}=1.0823$}$, $\stain{even_zeta}{$\zeta(6)=\frac{\pi^6}{945}=1.0173$}$ — endless sums collapsed into closed numbers. }

ROBOT: 2
  NAME { Isaac Newton }
  EXPLAIN_MATHEMATICIAN { To reach the higher coefficients you need to convert \emph{power sums} into \emph{elementary symmetric polynomials}. Newton's identities do exactly this: $\thread{t1}{ke_k=\sum_{i=1}^{k}(-1)^{i-1}e_{k-i}\,p_i}$, e.g. $\stain{sym_machinery}{$2e_2=e_1p_1-p_2$}$, $\stain{sym_machinery}{$3e_3=e_2p_1-e_1p_2+p_3$}$. }
  EXPLAIN_PHYSICIST { The product's coefficients are the $\stain{sym_machinery}{e_k}$ (sums of products of roots); the series knows the $\stain{power_sums}{p_k}$ (sums of powers of roots $=$ the zeta values). Newton's bridge ties them: $\thread{t1}{p_1=e_1}$, $\thread{t2}{p_2=e_1^2-2e_2}$, $\thread{t3}{p_3=e_1^3-3e_1e_2+3e_3}$. So knowing the $\stain{power_sums}{p_k}$ pins down the $\stain{sym_machinery}{e_k}$ and vice-versa. }
  EXPLAIN_BIOLOGIST { There are two ways to summarize a set of numbers: add up their powers, or add up their products. Newton found the exact dictionary translating one summary into the other. That dictionary is the gear that lets Euler's single trick keep going to higher and higher powers. }
  EXPLAIN_ENGINEER { Newton's dictionary in numbers: with $\stain{power_sums}{p_1}$ and $\stain{power_sums}{p_2}$ in hand, $\stain{sym_machinery}{$2e_2=p_1^2-p_2$}$. If $\thread{t1}{p_1=3}$ and $\thread{t2}{p_2=5}$ then $\stain{sym_machinery}{$e_2=\tfrac{9-5}{2}=2$}$ — power-sums in, symmetric-products out, no roots ever found. }

ROBOT: 3
  NAME { Albert Girard }
  EXPLAIN_MATHEMATICIAN { The objects Newton manipulates are the \emph{elementary symmetric polynomials} $\thread{t1}{e_k=\sum_{i_1<\cdots<i_k}X_{i_1}\cdots X_{i_k}}$, the signed coefficients in $\stain{sym_machinery}{$\prod_j(\lambda-X_j)=\lambda^n-e_1\lambda^{n-1}+e_2\lambda^{n-2}-\cdots$}$. Here the $X_j$ are the $\stain{roots}{\text{roots }-\pi^2/k^2}$ of $\sin x/x$. }
  EXPLAIN_PHYSICIST { An $\stain{sym_machinery}{e_k}$ is just "add up every product of $k$ distinct roots": $\thread{t1}{e_1=X_1+X_2+\cdots}$, $\thread{t2}{e_2=\sum_{i<j}X_iX_j}$, $\thread{t3}{e_3=\sum_{i<j<k}X_iX_jX_k}$. These are precisely the coefficients you read off the product expansion, with the $\stain{roots}{\text{roots}}$ plugged in. }
  EXPLAIN_BIOLOGIST { Take a handful of numbers. Add them all up — that is the first symmetric sum. Add up every pairwise product — the second. Every triple product — the third. These tidy "sums of products" are the building blocks every symmetric quantity is made from, and they are exactly the coefficients of a polynomial. }
  EXPLAIN_ENGINEER { With three numbers $\thread{t1}{X_1=1}$, $\thread{t2}{X_2=2}$, $\thread{t3}{X_3=3}$: the first symmetric sum is $\stain{sym_machinery}{$e_1=1+2+3=6$}$, the second is $\stain{sym_machinery}{$e_2=1\cdot2+1\cdot3+2\cdot3=11$}$, the third is $\stain{sym_machinery}{$e_3=1\cdot2\cdot3=6$}$ — and those are the coefficients of $(\lambda-1)(\lambda-2)(\lambda-3)$. }

ROBOT: 4
  NAME { Brook Taylor }
  EXPLAIN_MATHEMATICIAN { Packaging all coefficients at once gives a generating function. The clean result is $\stain{generating_fn}{$\zeta(2k)=[x^{2k}]\,\tfrac12\big(1-\pi x\cot(\pi x)\big)$}$: the $\stain{power_sums}{\text{even zeta values}}$ are literally the Taylor coefficients of $\stain{trig_fn}{$\tfrac12(1-\pi x\cot\pi x)$}$. }
  EXPLAIN_PHYSICIST { Instead of one coefficient at a time, expand a single function whose every even coefficient is a zeta value. That function is $\stain{trig_fn}{$\tfrac12\big(1-\pi x\cot\pi x\big)$}$, with Taylor expansion $\stain{generating_fn}{$\thread{t1}{\zeta(2)x^2}+\thread{t2}{\zeta(4)x^4}+\thread{t3}{\zeta(6)x^6}+\cdots$}$. Read off the $x^{2k}$ term to get $\zeta(2k)$. }
  EXPLAIN_BIOLOGIST { A generating function is one tidy formula that carries an entire list of numbers as its slope-coefficients. Taylor's expansion of the cotangent shape $\stain{trig_fn}{$1-\pi x\cot\pi x$}$ has the whole sequence $\zeta(2),\zeta(4),\zeta(6),\dots$ packed inside it, one per even power of $x$. }
  EXPLAIN_ENGINEER { Expand once, harvest forever. The Taylor series of $\stain{trig_fn}{$\tfrac12(1-\pi x\cot\pi x)$}$ reads $\stain{generating_fn}{$\thread{t1}{1.6449\,x^2}+\thread{t2}{1.0823\,x^4}+\thread{t3}{1.0173\,x^6}+\cdots$}$ — the coefficient of $x^{2k}$ is exactly $\zeta(2k)$, no separate computation per value. }

ROBOT: 5
  NAME { Gosta Mittag-Leffler }
  EXPLAIN_MATHEMATICIAN { Why does cotangent carry the zeta values? Because of its pole (partial-fraction) expansion $\stain{trig_fn}{$\pi\cot\pi x=\tfrac1x+2x\sum_{n=1}^{\infty}\thread{t1}{\frac{1}{x^2-n^2}}$}$, a Mittag-Leffler expansion summing one simple pole per $\stain{roots}{\text{integer root }n}$. Expanding each term geometrically releases the $\stain{power_sums}{\zeta(2k)}$. }
  EXPLAIN_PHYSICIST { Cotangent has a pole at every integer. Mittag-Leffler's theorem lets you write it as a sum of those poles: $\stain{trig_fn}{$\pi\cot\pi x=\frac1x+2x\sum_{n\ge1}\thread{t1}{\frac{1}{x^2-n^2}}$}$. Now expand $\thread{t1}{\frac{1}{x^2-n^2}}=\thread{t2}{-\frac{1}{n^2}\big(1+\frac{x^2}{n^2}+\cdots\big)}$; collecting powers of $x$ produces $\stain{power_sums}{$\sum 1/n^{2k}=\zeta(2k)$}$. }
  EXPLAIN_BIOLOGIST { Cotangent blows up at every whole number. There is a theorem that says you may rebuild such a function as a tidy sum, one simple piece for each place it blows up. Doing that for cotangent and tidying the pieces makes the sums-of-inverse-powers — the zeta values — fall right out. }
  EXPLAIN_ENGINEER { One pole per integer, summed. From $\stain{trig_fn}{$\pi\cot\pi x=\frac1x+2x\sum_{n\ge1}\thread{t1}{\frac{1}{x^2-n^2}}$}$, expanding gives the coefficient of $x^2$ as $\stain{power_sums}{$-2\sum 1/n^4$}$ and of $x^0$ inside as $\stain{power_sums}{$-2\sum 1/n^2=-2(1.6449)$}$ — the pole sum literally manufactures the zeta values. }

ROBOT: 6
  NAME { Jacob Bernoulli }
  EXPLAIN_MATHEMATICIAN { Matching cotangent's known Taylor coefficients, which carry the \emph{Bernoulli numbers} $\stain{power_sums}{B_{2n}}$ (from $\thread{t1}{\frac{t}{e^t-1}=\sum B_m\frac{t^m}{m!}}$), gives the closed form $\stain{even_zeta}{$\zeta(2n)=\frac{(-1)^{n-1}(2\pi)^{2n}}{2\,(2n)!}\,B_{2n}$}$. }
  EXPLAIN_PHYSICIST { The cotangent series has known coefficients built from the Bernoulli numbers $\stain{power_sums}{B_{2n}}$: $\stain{power_sums}{$B_2=\tfrac16$}$, $\stain{power_sums}{$B_4=-\tfrac1{30}$}$, $\stain{power_sums}{$B_6=\tfrac1{42}$}$. Equate them to the zeta coefficients and out drops $\stain{even_zeta}{$\zeta(2n)=\frac{(-1)^{n-1}(2\pi)^{2n}}{2(2n)!}B_{2n}$}$. Check: $n=1$ gives $\thread{t2}{\frac{(2\pi)^2}{2\cdot2!}\cdot\frac16=\frac{\pi^2}{6}}$. }
  EXPLAIN_BIOLOGIST { Long before Euler, Bernoulli found a sequence of fractions $\tfrac16,-\tfrac1{30},\tfrac1{42},\dots$ hiding in formulas for adding up powers. The very same fractions turn out to set the size of every even zeta value — one neat formula delivers all of them at once. }
  EXPLAIN_ENGINEER { Plug Bernoulli's fraction into the master formula. With $\stain{power_sums}{$B_2=\tfrac16=0.1667$}$ and $n=1$: $\stain{even_zeta}{$\zeta(2)=\frac{(2\pi)^2}{2\cdot2!}\cdot\frac16=\frac{\pi^2}{6}=1.6449$}$. Using $\stain{power_sums}{$B_4=-\tfrac1{30}$}$ gives $\stain{even_zeta}{$\zeta(4)=\frac{\pi^4}{90}=1.0823$}$. The same template, one Bernoulli number per value. }

ROBOT: 7
  NAME { Ferdinand von Lindemann }
  EXPLAIN_MATHEMATICIAN { Since each $\stain{even_zeta}{$\zeta(2n)=q_n\pi^{2n}$}$ with $q_n\in\mathbb{Q}$, and Lindemann proved $\pi$ (hence every $\pi^{2n}$) \emph{transcendental}, each $\stain{even_zeta}{\zeta(2n)}$ is transcendental. By contrast the odd values, including $\stain{power_sums}{\zeta(3)}$, resist: only its irrationality (Apery, $1978$) is known. }
  EXPLAIN_PHYSICIST { A transcendental number is no root of any integer polynomial — a much stronger wildness than mere irrationality. Lindemann ($1882$) proved $\stain{roots}{$\pi$}$ transcendental, so $\stain{roots}{$\pi^{2n}$}$ is too, and a rational multiple of it stays transcendental. Hence every $\stain{even_zeta}{\zeta(2n)}$ is transcendental — while $\stain{power_sums}{$\zeta(3)\approx1.2021$}$ is only known to be irrational. }
  EXPLAIN_BIOLOGIST { Some numbers can never be the answer to any whole-number equation — they are "transcendental," the wildest kind. Lindemann proved $\pi$ is one of these. Since each even zeta value is just a fraction times a power of $\pi$, all of them inherit that wildness. The odd ones, like $\zeta(3)$, stay mysterious to this day. }
  EXPLAIN_ENGINEER { Concretely: $\stain{even_zeta}{$\zeta(2)=1.6449$}$, $\stain{even_zeta}{$\zeta(4)=1.0823$}$ are transcendental because each equals a fraction times $\stain{roots}{$\pi^{2n}$}$ and $\pi$ itself is transcendental. The odd cousin $\stain{power_sums}{$\zeta(3)=1.2021$}$ is known irrational but its transcendence is still open. }
