ROBOT: 1
  NAME { Leonhard Euler }
  EXPLAIN_MATHEMATICIAN { The Basel trick generalizes: every even zeta value has a closed form $\displaystyle \stain{even_zeta}{$\zeta(2n)=\frac{(-1)^{n-1}(2\pi)^{2n}}{2\cdot(2n)!}\,B_{2n}$}$, where $\stain{bernoulli}{$B_{2n}$}$ is a Bernoulli number. Thus $\stain{even_zeta}{$\zeta(2)=\tfrac{\pi^2}{6}$}$, $\stain{even_zeta}{$\zeta(4)=\tfrac{\pi^4}{90}$}$, $\stain{even_zeta}{$\zeta(6)=\tfrac{\pi^6}{945}$}$, and so on. }
  EXPLAIN_PHYSICIST { Basel solved $\sum 1/n^2$. But the same machine keeps going: $\sum 1/n^4$, $\sum 1/n^6$, all of them. Each lands on a power of $\pi$ times a clean rational. Concretely $\stain{even_zeta}{$\zeta(4)=\frac{\pi^4}{90}$}$ and $\stain{even_zeta}{$\zeta(6)=\frac{\pi^6}{945}$}$. The general shape is $\stain{even_zeta}{$\zeta(2n)=\frac{(-1)^{n-1}(2\pi)^{2n}}{2\cdot(2n)!}B_{2n}$}$, blending the $\stain{pi_powers}{$\pi^{2n}$}$ with a rational $\stain{bernoulli}{$B_{2n}$}$. }
  EXPLAIN_BIOLOGIST { Adding up one-over-the-squares gave $\stain{even_zeta}{$\pi^2/6$}$. What if instead you add one-over-the-fourth-powers, or the sixth powers? Astonishingly, every even case works out to a power of $\pi$ times a tidy fraction: $\stain{even_zeta}{$\pi^4/90$}$, $\stain{even_zeta}{$\pi^6/945$}$, and onward forever. }
  EXPLAIN_ENGINEER { Plug in numbers. The fourth-power sum $\zeta(4)=\frac{\pi^4}{90}$ equals $1.0823$; the sixth-power sum $\zeta(6)=\frac{\pi^6}{945}$ equals $1.0173$. Each is a power of $\pi$ over a whole number: $\stain{even_zeta}{$\zeta(4)=\frac{\pi^4}{90}=1.0823$}$, $\stain{even_zeta}{$\zeta(6)=\frac{\pi^6}{945}=1.0173$}$. One formula computes them all. }

ROBOT: 2
  NAME { Isaac Newton }
  EXPLAIN_MATHEMATICIAN { Newton's identities link the two languages of a polynomial's roots. With $\stain{sym_poly}{$e_k$}$ the elementary symmetric polynomials and $p_k$ the power sums, $\displaystyle \stain{sym_to_power}{$k\,e_k=\sum_{i=1}^{k}(-1)^{i-1}e_{k-i}\,p_i$}$. Recursively this expresses $\thread{t1}{p_k}$ from the $\thread{t2}{e_j}$, the bridge from coefficients to $\thread{t1}{\text{power sums}}$. }
  EXPLAIN_PHYSICIST { A polynomial knows its roots two ways: through $\stain{sym_poly}{\text{symmetric combinations } $e_k$}$ (sums of products) and through $\thread{t1}{\text{power sums}}$ $\thread{t1}{p_k=\sum r_i^k}$. Newton's identities convert between them. For instance $\thread{t2}{2e_2}=\thread{t2}{e_1}\thread{t1}{p_1}-\thread{t1}{p_2}$, so $\thread{t1}{p_2}=\thread{t2}{e_1}^2-2\thread{t2}{e_2}$. Generally $\stain{sym_to_power}{$k\,e_k=\sum_{i=1}^{k}(-1)^{i-1}e_{k-i}\,p_i$}$. }
  EXPLAIN_BIOLOGIST { Suppose you know the roots of an equation but only through indirect clues. Newton found a recipe that turns one kind of clue — the $\stain{sym_poly}{\text{symmetric combinations of roots}}$ — into another: the $\stain{sym_to_power}{\text{sum of the roots' powers}}$. That recipe is the gear that drives the whole generalization. }
  EXPLAIN_ENGINEER { Newton's identities are a recurrence: feed in the symmetric pieces $\thread{t2}{e_1},\thread{t2}{e_2},\dots$ and crank out the power sums $\thread{t1}{p_1},\thread{t1}{p_2},\dots$ one at a time. Example: $\thread{t1}{p_1}=\thread{t2}{e_1}$, then $\thread{t1}{p_2}=\thread{t2}{e_1}^2-2\thread{t2}{e_2}$, then $\thread{t1}{p_3}=\thread{t2}{e_1}^3-3\thread{t2}{e_1}\thread{t2}{e_2}+3\thread{t2}{e_3}$. Each step is pure bookkeeping, and the $\stain{sym_to_power}{\text{conversion}}$ never gets stuck. }

ROBOT: 3
  NAME { Albert Girard }
  EXPLAIN_MATHEMATICIAN { Girard (1629) gave the explicit inversion: each power sum as a polynomial in the elementary symmetric ones, $\thread{t1}{p_2}=\thread{t2}{e_1^2-2e_2}$, $\thread{t1}{p_3}=\thread{t2}{e_1^3-3e_1e_2+3e_3}$. Applied to the roots $\stain{pi_powers}{$-\pi^2/k^2$}$ of $\sin(\pi x)/(\pi x)$, the power sums become $\stain{sym_to_power}{$\sum 1/k^{2}=\zeta(2)$, $\sum 1/k^{4}=\zeta(4)$, $\dots$}$. }
  EXPLAIN_PHYSICIST { Girard's formulas run Newton's machine the useful direction: they give each $\thread{t1}{\text{power sum}}$ directly. Expand $\thread{t1}{p_2}=\thread{t2}{e_1^2-2e_2}$ and $\thread{t1}{p_3}=\thread{t2}{e_1^3-3e_1e_2+3e_3}$. Now take the variables to be the roots of sine, $\stain{pi_powers}{$x_k=-\pi^2/k^2$}$. Then $p_1=-\pi^2\sum 1/k^2$, and matching this against the product's coefficient yields $\stain{sym_to_power}{$\zeta(2)=\frac{\pi^2}{6}$}$ — and the same play gives $\zeta(4),\zeta(6),\dots$. }
  EXPLAIN_BIOLOGIST { Girard wrote down, term by term, how to get the sum of the roots' powers from the simple symmetric clues. Once you feed in sine's special roots — which carry the number $\stain{pi_powers}{$\pi$}$ — these power sums turn into exactly the zeta values $\stain{sym_to_power}{$\zeta(2),\zeta(4),\zeta(6)$}$ you want. }
  EXPLAIN_ENGINEER { Use Girard's explicit formulas with the actual sine roots $\stain{pi_powers}{$x_k=-\pi^2/k^2$}$. The first power sum is $p_1=\thread{t2}{e_1}=-\pi^2\,\zeta(2)=-\pi^2\cdot 1.6449=-16.23$. The second, via $\thread{t1}{p_2}=\thread{t2}{e_1^2-2e_2}$, delivers $\zeta(4)$. Each $\stain{sym_to_power}{\text{conversion}}$ pins one more zeta value to an arithmetic of $\pi$-powers. }

ROBOT: 4
  NAME { Edward Waring }
  EXPLAIN_MATHEMATICIAN { The elementary symmetric polynomials are the building blocks: $\stain{sym_poly}{$e_1=\sum x_i$}$, $\stain{sym_poly}{$e_2=\sum_{i<j}x_ix_j$}$, $\stain{sym_poly}{$e_k=\sum_{i_1<\cdots<i_k}x_{i_1}\cdots x_{i_k}$}$. For $\sin(\pi x)/(\pi x)=\prod(1-x^2/k^2)$, the coefficient of $\thread{t1}{x^{2k}}$ is $(-1)^k\thread{t1}{e_k}$ of the $\stain{pi_powers}{$1/k^2$}$. }
  EXPLAIN_PHYSICIST { Before any conversion you need the raw symmetric pieces. The first elementary symmetric polynomial is $\stain{sym_poly}{$e_1=x_1+x_2+\cdots$}$ — just the sum. The second is $\stain{sym_poly}{$e_2=x_1x_2+x_1x_3+\cdots$}$ — every pairwise product. In a product like $\stain{sym_poly}{$\prod(1-\frac{x^2}{k^2})$}$ these $e_k$ are exactly the coefficients you read off term by term: the $\thread{t1}{x^{2}}$ coefficient is $-e_1$ of the $\stain{pi_powers}{$1/k^2$}$. }
  EXPLAIN_BIOLOGIST { When you multiply many simple factors together, the answer's coefficients are organized sums: first all the single pieces added up, then all the pairs multiplied and added, then all the triples, and so on. Those organized sums are the $\stain{sym_poly}{\text{symmetric building blocks}}$ Newton's recipe needs as ingredients. }
  EXPLAIN_ENGINEER { Multiply out a few factors and watch the blocks appear. For $\stain{sym_poly}{$(1-\frac{x^2}{1^2})(1-\frac{x^2}{2^2})(1-\frac{x^2}{3^2})$}$, the $\thread{t1}{x^2}$ coefficient is $-\stain{sym_poly}{$e_1$}=-(1+\tfrac14+\tfrac19)=-1.3611$, a partial slice of $\stain{pi_powers}{$\zeta(2)$}$. Add more factors and $\stain{sym_poly}{$e_1$}$ climbs toward $1.6449$. The blocks $\thread{t1}{e_k}$ are all you ever feed Newton. }

ROBOT: 5
  NAME { Jacob Bernoulli }
  EXPLAIN_MATHEMATICIAN { The rationals appearing are the Bernoulli numbers $\stain{bernoulli}{$B_{2n}$}$, defined by $\displaystyle \frac{t}{e^t-1}=\sum_{m\ge0}\thread{t1}{B_m}\frac{t^m}{m!}$, with $\stain{bernoulli}{$B_2=\tfrac16$}$, $\stain{bernoulli}{$B_4=-\tfrac{1}{30}$}$, $\stain{bernoulli}{$B_6=\tfrac{1}{42}$}$. They convert the power sums into the closed form $\stain{even_zeta}{$\zeta(2n)=\frac{(-1)^{n-1}(2\pi)^{2n}}{2(2n)!}B_{2n}$}$. }
  EXPLAIN_PHYSICIST { The clean rational in every even zeta value has a name: the Bernoulli number. They come from one generating function, $\frac{t}{e^t-1}=\sum \thread{t1}{B_m}\,t^m/m!$, and the relevant ones are $\stain{bernoulli}{$B_2=\frac16$}$, $\stain{bernoulli}{$B_4=-\frac{1}{30}$}$, $\stain{bernoulli}{$B_6=\frac{1}{42}$}$. Drop $B_2=\frac16$ into the formula and out comes $\stain{even_zeta}{$\zeta(2)=\frac{\pi^2}{6}$}$; $B_4=-\frac{1}{30}$ gives $\stain{even_zeta}{$\zeta(4)=\frac{\pi^4}{90}$}$. }
  EXPLAIN_BIOLOGIST { There is a famous list of fractions — $\tfrac16,-\tfrac{1}{30},\tfrac{1}{42},\dots$ — discovered by Jacob Bernoulli while adding up powers of whole numbers. These same $\stain{bernoulli}{\text{Bernoulli fractions}}$ turn out to be exactly the rational part sitting beside each power of $\pi$ in the zeta values. }
  EXPLAIN_ENGINEER { The Bernoulli numbers are fixed constants: $\stain{bernoulli}{$B_2=\frac16=0.1667$}$, $\stain{bernoulli}{$B_4=-\frac{1}{30}=-0.0333$}$, $\stain{bernoulli}{$B_6=\frac{1}{42}=0.0238$}$. Feed $B_4$ into $\stain{even_zeta}{$\frac{(2\pi)^4}{2\cdot 4!}|B_4|=\frac{\pi^4}{90}=1.0823$}$ and you recover $\zeta(4)$ exactly. The fraction is rational; only the $\stain{pi_powers}{$\pi$}$ is exotic. }

ROBOT: 6
  NAME { Ferdinand von Lindemann }
  EXPLAIN_MATHEMATICIAN { Since $\stain{even_zeta}{$\zeta(2k)$}$ is a rational multiple of $\stain{pi_powers}{$\pi^{2k}$}$ and Lindemann proved $\stain{pi_powers}{$\pi$}$ transcendental, every $\stain{transcendence}{$\zeta(2k)$ is transcendental}$. The Lindemann–Weierstrass theorem gives $e^\alpha$ transcendental for nonzero algebraic $\alpha$; with $e^{i\pi}=-1$ algebraic, $\pi$ cannot be algebraic. }
  EXPLAIN_PHYSICIST { We now know $\stain{even_zeta}{$\zeta(2k)=(\text{rational})\times\pi^{2k}$}$. A rational times a transcendental is still transcendental, so the only question is whether $\stain{pi_powers}{$\pi$}$ itself is transcendental. Lindemann settled it: if $e^{i\pi}=-1$ were built from an algebraic $\pi$, the Lindemann–Weierstrass theorem would force $-1$ to be transcendental — absurd. Hence $\stain{transcendence}{\text{every }$\zeta(2k)$ is transcendental}$. }
  EXPLAIN_BIOLOGIST { A "transcendental" number is one no ordinary polynomial equation can ever capture. Lindemann proved the circle number $\stain{pi_powers}{$\pi$}$ is one of them. Because each even zeta value is just a plain fraction times a power of $\pi$, that wildness passes straight through: every $\stain{transcendence}{\text{even zeta value is transcendental too}}$. }
  EXPLAIN_ENGINEER { Take $\zeta(4)=\frac{\pi^4}{90}$. The $\frac{1}{90}=0.0111$ is an ordinary rational; multiplying it by $\stain{pi_powers}{$\pi^4=97.409$}$ gives $1.0823$. Since $\pi$ is transcendental, so is $\pi^4$, and a rational times it stays transcendental: $\stain{transcendence}{$\zeta(4)=1.0823$ is transcendental}$. No polynomial with whole-number coefficients ever has it as a root. }

ROBOT: 7
  NAME { Roger Apery }
  EXPLAIN_MATHEMATICIAN { The odd zeta values resist this machinery. There is no sine product giving $\stain{transcendence}{$\zeta(2k+1)$}$ as a rational multiple of $\pi^{2k+1}$. Apéry (1979) proved only that $\stain{transcendence}{$\zeta(3)$ is irrational}$; whether $\zeta(3)$ is transcendental, and even whether $\zeta(5),\zeta(7),\dots$ are irrational, remains open. }
  EXPLAIN_PHYSICIST { Everything above worked because the even powers paired up as $\pm n\pi$ inside the product. The odd values $\stain{transcendence}{$\zeta(3),\zeta(5),\dots$}$ get no such closed form — the symmetric-polynomial trick simply does not reach them. The single hard-won fact is Apéry's: $\stain{transcendence}{$\zeta(3)=1.2020569\dots$ is irrational}$. Its transcendence is still unknown. }
  EXPLAIN_BIOLOGIST { The beautiful pattern stops at the even numbers. For the odd sums like one-over-the-cubes, nobody has ever found a clean formula with $\pi$. After centuries, the lone breakthrough was Apéry's proof that $\stain{transcendence}{\text{the cube sum }$\zeta(3)$ is irrational}$ — and even that was a shock. The rest stay mysterious. }
  EXPLAIN_ENGINEER { Compute $\zeta(3)=1+\frac{1}{8}+\frac{1}{27}+\cdots=1.2021$. Unlike $\zeta(2)=1.6449$, this number fits no formula of the form rational-times-$\pi^3$ that anyone has found. Apéry proved $\stain{transcendence}{$\zeta(3)=1.2021$ is irrational}$ — not even a fraction — but whether it is transcendental is unknown to this day. }
