ROBOT: 2
  NAME { Karl Weierstrass }
  EXPLAIN_MATHEMATICIAN { The normalized sinc has a Weierstrass product over the $\stain{roots}{$\text{zeros } \pm n\pi$}$: $\displaystyle \stain{product}{$\frac{\sin(\pi x)}{\pi x}=\prod_{n=1}^{\infty}\thread{t1}{\Big(1-\frac{x^2}{n^2}\Big)}$}$. As an entire function of finite order, $\stain{analytic}{$\sin(\pi x)$}$ is determined by its zeros up to an exponential factor, here trivial. }
  EXPLAIN_PHYSICIST { An ordinary polynomial is the product of one factor per root. Weierstrass proved the same assembly is legal for the entire function $\stain{analytic}{$\sin(\pi x)/(\pi x)$}$, whose $\stain{roots}{$\text{roots are }\pm1,\pm2,\dots$}$ (after dividing out the $\pi$). Pairing $+n$ with $-n$ gives $\stain{product}{$\prod_{n}\thread{t1}{(1-\frac{x^2}{n^2})}$}$. This product is exact and convergent. }
  EXPLAIN_BIOLOGIST { You can rebuild a polynomial from where it crosses zero — one factor for each crossing. Weierstrass showed you may do this even for a never-ending wave like $\stain{analytic}{\text{sinc}}$, multiplying a factor for each of its $\stain{roots}{\text{infinitely many crossings}}$. The result is the $\stain{product}{\text{infinite product}}$ this whole proof stands on. }
  EXPLAIN_ENGINEER { Engineers build a transfer function from its zeros, one factor each. Weierstrass certifies the same move for $\stain{analytic}{$\sin(\pi x)/(\pi x)$}$ over its zeros at every integer: $\stain{product}{$\prod(1-\frac{x^2}{n^2})$}$. With $x=\tfrac12$ the first factor is $\thread{t1}{1-\tfrac14}=\tfrac34$, and the whole product tends to [[ $2/\pi$ | 0.6366 ]]. }

ROBOT: 3
  NAME { Augustin-Louis Cauchy }
  EXPLAIN_MATHEMATICIAN { Take the $\stain{logderiv}{\text{logarithmic derivative}}$ of the $\stain{product}{\text{product}}$. Since $\tfrac{d}{dx}\ln\prod f_n=\sum f_n'/f_n$, term-by-term differentiation (justified by uniform convergence) gives $\displaystyle \pi\cot(\pi x)-\frac1x=-\sum_{n=1}^{\infty}\thread{t1}{\frac{2x}{n^2-x^2}}$. Dividing by $2x$ and regrouping yields $\displaystyle \stain{logderiv}{$\frac{1}{2x^2}-\frac{\pi\cot(\pi x)}{2x}=\sum_{n=1}^{\infty}\frac{1}{n^2-x^2}$}$. }
  EXPLAIN_PHYSICIST { Logarithms turn products into sums, so $\ln$ of the product becomes $\sum\ln(1-x^2/n^2)$. Differentiating each side — the right side termwise — and using $\tfrac{d}{dx}\ln\sin(\pi x)=\pi\cot(\pi x)$, we get $\stain{logderiv}{$\pi\cot(\pi x)-\frac1x=-\sum\thread{t1}{\frac{2x}{n^2-x^2}}$}$. Divide by $2x$ and tidy: $\stain{logderiv}{$\frac{1}{2x^2}-\frac{\pi\cot(\pi x)}{2x}=\sum\frac{1}{n^2-x^2}$}$. }
  EXPLAIN_BIOLOGIST { Here is a slick calculus habit: to differentiate a big product, first take its logarithm, which splits the product into a sum, then differentiate the easy pieces. Cauchy's careful theory says you may even do this term by term for an infinite product. Doing so turns our wave-product into a tidy $\stain{logderiv}{\text{sum of simple fractions}}$. }
  EXPLAIN_ENGINEER { Log-differentiation is the standard way to differentiate a long product: $\ln$ first, sum the pieces, then differentiate. Applied here it converts the product into $\stain{logderiv}{$\frac{1}{2x^2}-\frac{\pi\cot(\pi x)}{2x}=\sum\frac{1}{n^2-x^2}$}$. With $x=\tfrac12$ the first term is [[ $\thread{t1}{\frac{1}{2(1/4)}}$ | 2.000 ]]. }

ROBOT: 4
  NAME { Roger Cotes }
  EXPLAIN_MATHEMATICIAN { Substitute $x=-it$, so $n^2-x^2\mapsto n^2+t^2$, and rewrite $\cot$ via Euler's formula $\stain{hyperbolic}{$e^{i\theta}=\cos\theta+i\sin\theta$}$. Then $\displaystyle \frac{\pi\cot(-\pi i t)}{2it}=\frac{\pi}{2it}\,\thread{t1}{\frac{i(e^{2\pi t}+1)}{e^{2\pi t}-1}}=\frac{\pi}{2t}+\frac{\pi}{t(e^{2\pi t}-1)}$, converting the trigonometric cotangent into a real $\stain{hyperbolic}{\text{exponential}}$ expression. }
  EXPLAIN_PHYSICIST { Cotes' insight (later Euler's formula) is that $\stain{hyperbolic}{$e^{i\theta}=\cos\theta+i\sin\theta$}$, so cosine and sine are exponentials in disguise: $\cos\theta=\tfrac{e^{i\theta}+e^{-i\theta}}{2}$, $\sin\theta=\tfrac{e^{i\theta}-e^{-i\theta}}{2i}$. Setting $x=-it$ and feeding these in, the cotangent of an imaginary angle becomes the real ratio $\stain{hyperbolic}{$\thread{t1}{\frac{e^{2\pi t}+1}{e^{2\pi t}-1}}$}$ — pure exponentials, no trigonometry left. }
  EXPLAIN_BIOLOGIST { Cotes (and then Euler) discovered that the spinning of sine and cosine is really the growth of the exponential, viewed sideways through imaginary numbers. So if you let the angle become imaginary, the wiggly cotangent quietly turns into a smooth ratio of $\stain{hyperbolic}{\text{exponentials}}$ — easier to handle and ready for the limit ahead. }
  EXPLAIN_ENGINEER { Euler's formula $\stain{hyperbolic}{$e^{i\theta}=\cos\theta+i\sin\theta$}$ is the bridge from trig to exponentials. Replacing $x=-it$ turns $\cot$ into [[ $\frac{e^{2\pi t}+1}{e^{2\pi t}-1}$ | 1.0037 ]] at $t=1$; as $t$ grows it tends to [[ $1$ | 1.000 ]]. }

ROBOT: 5
  NAME { Vincenzo Riccati }
  EXPLAIN_MATHEMATICIAN { The exponential ratio is exactly the hyperbolic cotangent: $\coth u=\tfrac{e^{u}+e^{-u}}{e^{u}-e^{-u}}$, and $\cot(i u)=i\coth u$. Hence $\displaystyle \frac{\pi\cot(-\pi it)}{2it}=\stain{hyperbolic}{$\frac{\pi}{2t}\coth(\pi t)$}$, and the sum becomes $\displaystyle \sum_{n=1}^{\infty}\frac{1}{n^2+t^2}=-\frac{1}{2t^2}+\stain{hyperbolic}{$\frac{\pi}{2t}\coth(\pi t)$}$. }
  EXPLAIN_PHYSICIST { Riccati's hyperbolic functions are the exponential twins of sine and cosine: $\stain{hyperbolic}{$\coth u=\thread{t1}{\frac{e^{u}+e^{-u}}{e^{u}-e^{-u}}}$}$. The messy exponential ratio from the last step is precisely $\coth(\pi t)$ (up to the $i$'s that cancel). So the equation tidies to $\stain{hyperbolic}{$\sum\frac{1}{n^2+t^2}=-\frac{1}{2t^2}+\frac{\pi}{2t}\coth(\pi t)$}$ — clean and ready for a limit. }
  EXPLAIN_BIOLOGIST { Riccati named a family of functions, the hyperbolic ones, that behave like sine and cosine but are built from the exponential instead of the circle. The exponential ratio we just made is simply one of them, $\stain{hyperbolic}{\text{hyperbolic cotangent}}$. Naming it that way turns a scary formula into a familiar, named object we can take a limit of. }
  EXPLAIN_ENGINEER { The hyperbolic cotangent $\stain{hyperbolic}{$\coth u=\thread{t1}{\frac{e^{u}+e^{-u}}{e^{u}-e^{-u}}}$}$. At $u=\pi$ this gives [[ $\coth(\pi)$ | 1.0037 ]]. The equation becomes $\stain{hyperbolic}{$\sum\frac{1}{n^2+t^2}=-\frac{1}{2t^2}+\frac{\pi}{2t}\coth(\pi t)$}$. ROBOT: 6
  NAME { Guillaume de l'Hopital }
  EXPLAIN_MATHEMATICIAN { Let $t\to0$ in $\stain{analytic}{$\sum\frac{1}{n^2+t^2}$}$. The right side $-\tfrac{1}{2t^2}+\tfrac{\pi}{2t}\coth(\pi t)$ is an indeterminate $\tfrac00$ after combining; applying $\stain{analytic}{\text{L'H\^opital's rule}}$ thrice removes the indeterminacy: $\displaystyle \stain{answer}{$\sum_{n=1}^{\infty}\frac{1}{n^2}=\lim_{t\to0}\thread{t1}{\frac{\pi^2(2\pi t+1)}{4\pi^2 t^2+12\pi t+6}}=\frac{\pi^2}{6}$}$. }
  EXPLAIN_PHYSICIST { As $t\to0$ both pieces blow up, but their difference is finite — a $\tfrac00$ form. L'H\^opital's rule says: when a quotient is $\tfrac00$, differentiate top and bottom and try again. Three passes turn the tangle into the harmless ratio $\stain{analytic}{$\thread{t1}{\frac{\pi^2(2\pi t+1)}{4\pi^2 t^2+12\pi t+6}}$}$. Setting $t=0$ gives $\stain{answer}{$\frac{\pi^2\cdot 1}{6}=\frac{\pi^2}{6}$}$. }
  EXPLAIN_BIOLOGIST { When a fraction tries to become $\tfrac00$ — zero over zero, which says nothing — L'H\^opital's rule rescues it: replace top and bottom by how fast each is changing, and look again. Do this three times here and the runaway pieces settle into a plain fraction whose value at the end is exactly $\stain{answer}{$\pi^2/6$}$. }
  EXPLAIN_ENGINEER { L'H\^opital handles $\tfrac00$ by differentiating top and bottom. After three passes the limit is $\stain{analytic}{$\thread{t1}{\frac{\pi^2(2\pi t+1)}{4\pi^2 t^2+12\pi t+6}}$}$. Plug $t=0$: numerator [[ $\pi^2$ | 9.8696 ]] over denominator [[ $6$ | 6.000 ]], giving $\stain{answer}{$\frac{\pi^2}{6}$}=$ [[ $\frac{\pi^2}{6}$ | 1.6449 ]]. }

ROBOT: 7
  NAME { Jules Tannery }
  EXPLAIN_MATHEMATICIAN { Passing $\lim_{t\to0}$ inside the infinite sum requires justification. Tannery's theorem: if $\stain{analytic}{$\lvert a_k(t)\rvert\le M_k$}$ with $\sum M_k<\infty$, then $\lim\sum a_k=\sum\lim a_k$. Here $\thread{t1}{\frac{1}{n^2+t^2}}\le \thread{t1}{\frac{1}{n^2}}$ and $\sum\tfrac1{n^2}<\infty$, so $\displaystyle \lim_{t\to0}\sum_{n=1}^{\infty}\frac{1}{n^2+t^2}=\stain{answer}{$\sum_{n=1}^{\infty}\frac{1}{n^2}$}$. }
  EXPLAIN_PHYSICIST { Why may we move the limit through an infinite sum? Tannery's theorem gives the license: if each term is bounded by a fixed $M_k$ whose total $\sum M_k$ is finite (a dominating tail), the swap is safe. Here each term $\thread{t1}{\frac{1}{n^2+t^2}}$ is dominated by $\thread{t1}{\frac{1}{n^2}}$, and $\sum 1/n^2$ converges, so $\lim$ and $\sum$ may trade places to leave exactly $\stain{answer}{$\sum 1/n^2$}$. }
  EXPLAIN_BIOLOGIST { When you have an endless sum that also depends on a sliding number $t$, you cannot always take the limit term by term — unless something keeps the tail under control. Tannery's theorem is that safety check: if every term stays under a fixed, finite budget, swapping the limit inside is allowed, and the sum becomes the plain $\stain{answer}{\text{Basel sum}}$. }
  EXPLAIN_ENGINEER { Tannery's theorem licenses swapping $\lim$ and $\sum$ when each term is capped by a convergent bound. Here [[ $\frac{1}{n^2+t^2}$ | 1.000 ]] at $n=1,t=0$ is below the cap [[ $\frac{1}{n^2}$ | 1.000 ]], and [[ $\sum 1/n^2$ | 1.6449 ]] is finite. So the limit slides in and the sum reduces to $\stain{answer}{$\sum 1/n^2$}$. }
