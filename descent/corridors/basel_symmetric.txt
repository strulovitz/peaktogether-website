ROBOT: 2
NAME { Isaac Newton }
BRIEFING_HINT { Newton's identities: the recurrence converting symmetric pieces of the
          roots into power sums. This sentinel yields to their discoverer. }
PROBLEM { A recurrence turns the symmetric pieces $e_k$ of a polynomial's roots into the
          power sums $p_k$. Whose identities give $k e_k = \sum (-1)^{i-1} e_{k-i} p_i$? }
EXPLAIN_MATHEMATICIAN { Newton's identities link the two languages of a polynomial's
          roots. With $e_k$ the elementary symmetric polynomials and $p_k$ the power sums,
          $k e_k = \sum_{i=1}^{k} (-1)^{i-1} e_{k-i} p_i$. Recursively this expresses
          $p_k$ from the $e_j$, the bridge from coefficients to power sums. }
EXPLAIN_PHYSICIST { A polynomial knows its roots two ways: through symmetric combinations
          $e_k$ (sums of products) and through power sums $p_k = \sum r_i^k$. Newton's
          identities convert between them. For instance $2 e_2 = e_1 p_1 - p_2$, so
          $p_2 = e_1^2 - 2 e_2$. Generally $k e_k = \sum_{i=1}^{k} (-1)^{i-1} e_{k-i} p_i$. }
EXPLAIN_BIOLOGIST { Suppose you know the roots of an equation, but only through indirect
          clues. Newton found a recipe turning one kind of clue -- the symmetric
          combinations of roots -- into another: the sum of the roots' powers. That recipe
          is the gear driving the whole generalization. }
EXPLAIN_ENGINEER { Newton's identities are a recurrence: feed in the symmetric pieces
          [[ $e_1$ | 1.000 ]], [[ $e_2$ | 2.000 ]] and crank out the power sums one at a
          time. With $e_1 = 1$ and $e_2 = 2$, $p_1 = e_1$ gives [[ $p_1$ | 1.000 ]], then
          $p_2 = e_1^2 - 2 e_2$ gives [[ $e_1^2 - 2 e_2$ | -3.000 ]]. Each step is pure
          bookkeeping. }

ROBOT: 3
NAME { Albert Girard }
BRIEFING_HINT { The explicit inversion: each power sum written directly as a polynomial in
          the symmetric pieces. This sentinel yields to the man who wrote them first, in 1629. }
PROBLEM { Run the identities the useful way: write $p_2 = e_1^2 - 2 e_2$, $p_3 = e_1^3 - 3
          e_1 e_2 + 3 e_3$ directly. Who first set down these explicit power-sum formulas? }
EXPLAIN_MATHEMATICIAN { Girard (1629) gave the explicit inversion: each power sum as a
          polynomial in the elementary symmetric ones, $p_2 = e_1^2 - 2 e_2$, $p_3 = e_1^3
          - 3 e_1 e_2 + 3 e_3$. Applied to the roots $-\pi^2/k^2$ of $\sin(\pi x)/(\pi x)$,
          the power sums become $\sum 1/k^2 = \zeta(2)$, $\sum 1/k^4 = \zeta(4)$, and so on. }
EXPLAIN_PHYSICIST { Girard's formulas run Newton's machine the useful direction: they give
          each power sum directly. Expand $p_2 = e_1^2 - 2 e_2$ and $p_3 = e_1^3 - 3 e_1 e_2
          + 3 e_3$. Take the variables to be sine's roots, $x_k = -\pi^2/k^2$. Then $p_1 =
          -\pi^2 \sum 1/k^2$, and matching it against the product gives $\zeta(2) =
          \frac{\pi^2}{6}$ -- and the same play gives $\zeta(4), \zeta(6), \dots$. }
EXPLAIN_BIOLOGIST { Girard wrote down, term by term, how to get the sum of the roots'
          powers from the simple symmetric clues. Once you feed in sine's special roots --
          which carry the number $\pi$ -- these power sums turn into exactly the zeta
          values $\zeta(2), \zeta(4), \zeta(6)$ you want. }
EXPLAIN_ENGINEER { Use Girard's explicit formulas with the actual sine roots $x_k =
          -\pi^2/k^2$. The first power sum is $p_1 = e_1 = -\pi^2 \zeta(2)$, which equals
          [[ $-\pi^2 \cdot 1.6449$ | -16.235 ]]. The second, via [[ $e_1^2 - 2 e_2$ | -3.000 ]],
          delivers $\zeta(4)$. Each conversion pins one more zeta value to an arithmetic of
          $\pi$-powers. }

ROBOT: 4
NAME { Edward Waring }
BRIEFING_HINT { The elementary symmetric polynomials: the organized sums of products that
          are a polynomial's coefficients. This sentinel yields to a champion of symmetric functions. }
PROBLEM { Multiplying out $\prod(1 - x^2/k^2)$, the coefficients are organized sums:
          $e_1 = \sum x_i$, $e_2 = \sum_{i<j} x_i x_j$. What are these building blocks called? }
EXPLAIN_MATHEMATICIAN { The elementary symmetric polynomials are the building blocks:
          $e_1 = \sum x_i$, $e_2 = \sum_{i<j} x_i x_j$, $e_k = \sum_{i_1 < \cdots < i_k}
          x_{i_1} \cdots x_{i_k}$. For $\sin(\pi x)/(\pi x) = \prod(1 - x^2/k^2)$, the
          coefficient of $x^{2k}$ is $(-1)^k e_k$ of the $1/k^2$. }
EXPLAIN_PHYSICIST { Before any conversion you need the raw symmetric pieces. The first is
          $e_1 = x_1 + x_2 + \cdots$ -- just the sum. The second is $e_2 = x_1 x_2 + x_1 x_3
          + \cdots$ -- every pairwise product. In a product like $\prod(1 - \frac{x^2}{k^2})$
          these $e_k$ are exactly the coefficients you read off term by term: the $x^2$
          coefficient is $-e_1$ of the $1/k^2$. }
EXPLAIN_BIOLOGIST { When you multiply many simple factors together, the answer's
          coefficients are organized sums: first all the single pieces added up, then all
          the pairs multiplied and added, then all the triples, and so on. Those organized
          sums are the symmetric building blocks Newton's recipe needs as ingredients. }
EXPLAIN_ENGINEER { Multiply out a few factors and watch the blocks appear. For $(1 -
          \frac{x^2}{1})(1 - \frac{x^2}{4})(1 - \frac{x^2}{9})$, the $x^2$ coefficient is
          $-e_1 = -(1 + \frac{1}{4} + \frac{1}{9})$, which equals [[ $1 + \frac{1}{4} + \frac{1}{9}$ | 1.3611 ]].
          Add more factors and $e_1$ climbs toward [[ $\zeta(2)$ | 1.6449 ]]. The blocks $e_k$
          are all you ever feed Newton. }

ROBOT: 6
NAME { Ferdinand von Lindemann }
BRIEFING_HINT { Transcendence of pi: since each even zeta is a rational times a power of
          pi, and pi is transcendental, so is every even zeta. This sentinel yields to the prover. }
PROBLEM { Each $\zeta(2k)$ is a rational multiple of $\pi^{2k}$, and a rational times a
          transcendental stays transcendental. Who proved $\pi$ itself is transcendental? }
EXPLAIN_MATHEMATICIAN { Since $\zeta(2k)$ is a rational multiple of $\pi^{2k}$ and Lindemann
          proved $\pi$ transcendental, every $\zeta(2k)$ is transcendental. The
          Lindemann-Weierstrass theorem gives $e^{\alpha}$ transcendental for nonzero
          algebraic $\alpha$; with $e^{i\pi} = -1$ algebraic, $\pi$ cannot be algebraic. }
EXPLAIN_PHYSICIST { We now know $\zeta(2k) = (\text{rational}) \times \pi^{2k}$. A rational
          times a transcendental is still transcendental, so the only question is whether
          $\pi$ itself is transcendental. Lindemann settled it: if $e^{i\pi} = -1$ were
          built from an algebraic $\pi$, the Lindemann-Weierstrass theorem would force $-1$
          to be transcendental -- absurd. Hence every $\zeta(2k)$ is transcendental. }
EXPLAIN_BIOLOGIST { A "transcendental" number is one no ordinary polynomial equation can
          ever capture. Lindemann proved the circle number $\pi$ is one of them. Because
          each even zeta value is just a plain fraction times a power of $\pi$, that
          wildness passes straight through: every even zeta value is transcendental too. }
EXPLAIN_ENGINEER { Take $\zeta(4) = \frac{\pi^4}{90}$. The [[ $\frac{1}{90}$ | 0.0111 ]] is an
          ordinary rational; multiplying it by [[ $\pi^4$ | 97.409 ]] gives [[ $\zeta(4)$ | 1.0823 ]].
          Since $\pi$ is transcendental, so is $\pi^4$, and a rational times it stays
          transcendental. No polynomial with whole-number coefficients ever has $\zeta(4)$ as a root. }
