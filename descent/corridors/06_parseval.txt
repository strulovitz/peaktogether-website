ROBOT: 2
NAME { Pythagoras }
BRIEFING_HINT { The geometric heart: a squared length equals the sum of its squared

PROBLEM { Parseval is just one theorem stretched to infinitely many right angles:

EXPLAIN_MATHEMATICIAN { Parseval is the Pythagorean theorem in a Hilbert space:
          $\lVert x \rVert^2 = \sum_k \lvert \langle x, e_k \rangle \rvert^2$. For orthogonal $u \perp v$,
          $\lVert u+v \rVert^2 = \lVert u \rVert^2 + \lVert v \rVert^2$; extended to a complete orthonormal family,
          this is the identity itself. }
EXPLAIN_PHYSICIST { In the plane, $c^2 = a^2 + b^2$: the squared length is the sum of
          squared components along perpendicular axes. A Hilbert space just has
          infinitely many perpendicular axes $e_k$, so $\lVert x \rVert^2$ becomes the infinite
          sum $\sum_k \lvert \langle x, e_k \rangle \rvert^2$ of squared components. }
EXPLAIN_BIOLOGIST { Right triangle: the long side squared equals the sum of the two
          short sides squared. Now picture a shape with infinitely many corners, all
          at right angles. Its length squared is still just the sum of all its squared
          shadows on those directions. That is all Parseval says. }
EXPLAIN_ENGINEER { Pythagoras with numbers: legs $a$ and $b$ give hypotenuse
          $\sqrt{a^2 + b^2}$. With unit-length perpendicular axes, the squared length
          is the running total of the squared components -- and infinitely many axes is
          fine, the total still converges. }

  $\lVert u+v \rVert^2$              | norm
  $=$                                | NEUTRAL

EXPLAIN_MATHEMATICIAN { The complex exponentials $e_k(\vartheta) = e^{2\pi i k\vartheta}$
          are orthonormal: $\langle e_k, e_j \rangle = \int_0^1 e^{2\pi i(k-j)\vartheta}
          \, d\vartheta = \delta_{k,j}$. The coordinates of $f$ in this basis are the
          coefficients $\langle f, e_k \rangle = \int_0^1 f(\vartheta) e^{-2\pi i k\vartheta}
          \, d\vartheta$. }
EXPLAIN_PHYSICIST { The axes are the pure waves $e_k = e^{2\pi i k\vartheta}$, one per
          integer frequency $k$. They are mutually perpendicular and unit length:
          $\langle e_k, e_j \rangle = \delta_{k,j}$ (one if $k=j$, zero otherwise). A
          function's coordinate along wave $k$ is its coefficient $\langle f, e_k \rangle$. }
EXPLAIN_BIOLOGIST { The big idea: any repeating wiggle is a stack of pure, evenly spaced
          tones. Those tones are the building-block waves, all at right angles to one
          another. How much of each tone is present is that tone's coefficient -- found
          by overlapping the function with that wave. }
EXPLAIN_ENGINEER { The basis is the bank of pure tones $e^{2\pi i k\vartheta}$ for
          $k = \dots, -1, 0, 1, \dots$. They are orthonormal:

          correlate the signal against it, giving
          $\langle f, e_k \rangle = \int_0^1 f e^{-2\pi i k\vartheta} \, d\vartheta$. }

ROBOT: 5
NAME { Brook Taylor }
BRIEFING_HINT { Integration by parts: trade a hard integral for an easy one to compute
          the ramp's coefficient. This sentinel yields to the discoverer of that rule. }
PROBLEM { Computing $\int_0^1 \vartheta e^{-2\pi i k\vartheta} d\vartheta$ uses
          $\int u\,dv = uv - \int v\,du$ to extract $-\frac{1}{2\pi i k}$. Who discovered
          this method? }
EXPLAIN_MATHEMATICIAN { For $f(\vartheta) = \vartheta$, integration by parts gives
          $\langle f, e_k \rangle = \int_0^1 \vartheta e^{-2\pi i k\vartheta} \, d\vartheta
          = -\frac{1}{2\pi i k}$ for $k \neq 0$, and $\frac{1}{2}$ for $k = 0$. Thus
          $\lvert \langle f, e_k \rangle \rvert^2 = \frac{1}{(2\pi k)^2}$. }
EXPLAIN_PHYSICIST { Integration by parts, $\int u\,dv = uv - \int v\,du$, turns
          $\int_0^1 \vartheta e^{-2\pi i k\vartheta} d\vartheta$ into a boundary term
          minus an easy integral. The leftover oscillation integrates to zero over a
          full period, leaving $\langle f, e_k \rangle = -\frac{1}{2\pi i k}$, so
          $\lvert \langle f, e_k \rangle \rvert^2 = \frac{1}{4\pi^2 k^2}$. }
EXPLAIN_BIOLOGIST { To overlap the ramp $\vartheta$ with a wave we use a trick that
          trades a hard integral for an easy one: differentiate the simple part,
          integrate the wavy part. The wavy leftover averages to nothing over a whole
          cycle, leaving one clean coefficient for each frequency. }
EXPLAIN_ENGINEER { Integration by parts is the lever: $\int u\,dv = uv - \int v\,du$.
          For $\int_0^1 \vartheta e^{-2\pi i k\vartheta} d\vartheta$ pick $u = \vartheta$
          and $dv = e^{-2\pi i k\vartheta} d\vartheta$; the periodic remainder vanishes,
          giving $\langle f, e_k \rangle = -\frac{1}{2\pi i k}$ and squared size
          $\frac{1}{(2\pi k)^2}$. }
SEGMENTS {
  $\int u\,dv$                            | coefficients
  $=$                                     | NEUTRAL
  $uv - \int v\,du$                       | norm
}

NAME { Leonhard Euler }
BRIEFING_HINT { The assembly: set the ramp's energy 1/3 equal to the summed squared
          coefficients and solve. This sentinel yields to the man who first found pi^2/6. }
PROBLEM { Set $\int_0^1 \vartheta^2 d\vartheta = \frac{1}{3}$ equal to the spectral sum
          and rearrange to recover $\frac{\pi^2}{6}$. Who first proved this value? }
EXPLAIN_MATHEMATICIAN { Parseval now reads
          $\lVert f \rVert^2 = \int_0^1 \vartheta^2 d\vartheta = \frac{1}{3} = \sum_{k \neq 0}
          \frac{1}{(2\pi k)^2} + \frac{1}{4} = 2\sum_{k \geq 1} \frac{1}{(2\pi k)^2} +
          \frac{1}{4}$. Solving, $\frac{\pi^2}{6} = \zeta(2)$. }
EXPLAIN_PHYSICIST { Set the two sides equal. Left: $\int_0^1 \vartheta^2 d\vartheta =
          \frac{1}{3}$. Right: the $k=0$ term $\frac{1}{4}$ plus twice the tail
          $2\sum_{k \geq 1} \frac{1}{4\pi^2 k^2}$. So
          $\frac{1}{3} - \frac{1}{4} = \frac{1}{2\pi^2} \sum_{k \geq 1} \frac{1}{k^2}$,
          giving $\sum \frac{1}{k^2} = \frac{\pi^2}{6}$. }
EXPLAIN_BIOLOGIST { Now just balance the books. The whole-function energy is
          $\frac{1}{3}$. The tones contribute a flat piece $\frac{1}{4}$ plus a tail
          made of $1/k^2$ pieces. Forcing the two totals to match rearranges into the
          famous sum $\frac{\pi^2}{6}$ -- the same Basel answer, a brand-new way. }
EXPLAIN_ENGINEER { Energy balance with numbers: the time side is
          [[ $\int_0^1 \vartheta^2 d\vartheta$ | 0.3333 ]]; the spectral side is the DC
          term [[ $\frac{1}{4}$ | 0.2500 ]] plus the harmonic tail. Subtract, multiply
          by $2\pi^2$, and the tail sums to [[ $\frac{\pi^2}{6}$ | 1.6449 ]] --
          Basel solved through pure energy accounting. }
