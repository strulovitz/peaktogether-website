BRIEFING_HINT { Interchanging sum and integral: integrate the series term by term so
          the integral becomes the Basel sum. This sentinel yields to the man whose
          theorem licenses the swap. }
PROBLEM { The integral of an infinite sum is computed by swapping integral and sum,
          integrating each term. Whose theorem justifies interchanging them here? }
EXPLAIN_MATHEMATICIAN { Interchanging sum and integral, $\int_0^\infty \ln(1 - e^{-x})
          \, dx = -\sum_{n=1}^{\infty} \int_0^\infty \frac{e^{-nx}}{n}\, dx =
          -\sum_{n=1}^{\infty} \frac{1}{n^2}$, since $\int_0^\infty e^{-nx} dx = 1/n$.
          The swap is justified because the terms are nonnegative. }
EXPLAIN_PHYSICIST { Now add up the ladder. Each term integrates trivially,
          $\int_0^\infty e^{-nx} dx = 1/n$, and dividing by the $n$ already there makes
          $1/n^2$. Summing, the integral becomes $-\sum \frac{1}{n^2}$ -- the integral
          has turned into the Basel sum. }
EXPLAIN_BIOLOGIST { We have a sum of integrals; this theorem lets us swap the order --
          integrate first, then add. Each little integral gives $1/n$, which paired with
          its $1/n$ becomes $1/n^2$. Adding them all, the whole integral equals
          $-\sum \frac{1}{n^2}$. }
EXPLAIN_ENGINEER { Swap $\int$ and $\sum$ (legal here: all terms one sign). Each piece
          gives [[ $\int_0^\infty e^{-nx} dx$ at $n=1$ | 1 ]] $= 1/n$, times the $1/n$
          out front $= 1/n^2$. The integral collapses to $-\sum \frac{1}{n^2}$. }

  $\int_0^\infty \ln(1 - e^{-x})\, dx$                                      | log_series_sum
  $=$                                                                      | NEUTRAL
