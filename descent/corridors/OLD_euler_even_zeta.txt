ROBOT: 1
  NAME { Leonhard Euler }
  EXPLAIN_MATHEMATICIAN { Euler's product method, pushed past $\zeta(2)$, yields every even zeta constant in \stain{closed}{closed form}: $\displaystyle \stain{evenzeta}{\zeta(2n)} = \frac{(-1)^{n-1}(2\pi)^{2n}}{2\,(2n)!}\,B_{2n}$, with $B_{2n}$ the Bernoulli numbers. Thus $\stain{evenzeta}{\zeta(4)}=\tfrac{\pi^4}{90}$, $\stain{evenzeta}{\zeta(6)}=\tfrac{\pi^6}{945}$, and so on. The descent below shows how the \stain{product}{sine product} forces this. }
  EXPLAIN_PHYSICIST { Solving Basel gave $\stain{evenzeta}{\zeta(2)}=\pi^2/6$. The same trick keeps giving: each even sum $\stain{zeta}{\sum 1/k^{2n}}$ comes out as a rational number times $\pi^{2n}$. The rational part is packaged by the \stain{closed}{Bernoulli numbers} $B_{2n}$ in $\stain{closed}{\zeta(2n)=\frac{(-1)^{n-1}(2\pi)^{2n}}{2(2n)!}B_{2n}}$. We are descending to see why $\pi$ shows up every time. }
  EXPLAIN_BIOLOGIST { Euler found $1+\tfrac14+\tfrac19+\cdots=\pi^2/6$. The surprise: the trick never stops. Add up $1/k^4$, $1/k^6$, and you always get \stain{closed}{some plain fraction times a power of $\pi$}. There is one master recipe — the \stain{closed}{Bernoulli numbers} — that spits out the fraction every time. }
  EXPLAIN_ENGINEER { These \stain{evenzeta}{even zeta values} are not idle: $\stain{evenzeta}{\zeta(4)}$ sets the Stefan–Boltzmann constant for blackbody radiation. Euler's method is a reusable factory: feed it an index $2n$, turn the \stain{closed}{Bernoulli crank}, read off $\zeta(2n)$ as a clean multiple of $\pi^{2n}$. No infinite summing required. }

ROBOT: 2
  NAME { The Sine Product }
  EXPLAIN_MATHEMATICIAN { Treat $\sin$ like a polynomial built from its roots $0,\pm\pi,\pm2\pi,\dots$: $\displaystyle \stain{product}{\frac{\sin x}{x}=\prod_{k=1}^{\infty}\Bigl(1-\frac{x^2}{k^2\pi^2}\Bigr)}$. Truncating gives $\frac{S_n(x)}{x}=\prod_{k=1}^n\thread{t1}{(1-\tfrac{x^2}{k^2\pi^2})}$. Each factor is the contribution of one \stain{product}{root} $\pm k\pi$. Expanding this product is the engine of the whole method. }
  EXPLAIN_PHYSICIST { A finite polynomial equals (leading constant) times $\prod(1-x/r_i)$ over its roots $r_i$. Euler dared to do the same with $\sin$: its roots are the multiples of $\pi$, so $\stain{product}{\frac{\sin x}{x}=\prod_k\thread{t1}{(1-x^2/k^2\pi^2)}}$. Every $\pi$ in the answer enters right here, through the \stain{product}{roots}. }
  EXPLAIN_BIOLOGIST { Any polynomial can be rebuilt from where it crosses zero. The sine wave crosses zero at $0,\pm\pi,\pm2\pi,\dots$, so Euler wrote it as an endless product, \stain{product}{one bracket per crossing}: $\stain{product}{\frac{\sin x}{x}=(1-\tfrac{x^2}{\pi^2})(1-\tfrac{x^2}{4\pi^2})\cdots}$. The crossings live at multiples of $\pi$, which is why $\pi$ haunts every answer. }
  EXPLAIN_ENGINEER { Think of $\sin$ as a filter with zeros at $k\pi$. You reconstruct the whole transfer function from its zero locations: $\stain{product}{\sin x / x=\prod\thread{t1}{(1-x^2/k^2\pi^2)}}$. Once you have this \stain{product}{factored form}, multiplying the brackets out exposes the coefficients you actually want to harvest. }

ROBOT: 3
  NAME { Coefficient Extraction }
  EXPLAIN_MATHEMATICIAN { A formal power series records only its coefficients; the operator $[x^m]$ reads one off: $[x^m]\sum a_n x^n = a_m$. From the Taylor side, $\stain{product}{\frac{\sin x}{x}}=\sum_{n\ge0}\frac{(-1)^n x^{2n}}{(2n+1)!}$, so $[x^4]\tfrac{\sin x}{x}=\tfrac{1}{120}$. Matching $[x^{2k}]$ of the \stain{product}{product} against $[x^{2k}]$ of this series is what pins down the zeta values. }
  EXPLAIN_PHYSICIST { Forget convergence — a power series is just its list of coefficients, and $[x^m]$ grabs entry $m$. We have two expressions for the same object: the \stain{product}{product} and the Taylor series $\frac{\sin x}{x}=1-\frac{x^2}{6}+\frac{x^4}{120}-\cdots$. Equating their $[x^{2k}]$ coefficients is the whole game. }
  EXPLAIN_BIOLOGIST { A power series is like a barcode: each power of $x$ has its own stripe. The bracket $[x^4]$ just means "read the stripe on $x^4$." Euler reads the same stripe two ways — once from the \stain{product}{product}, once from the familiar wiggly Taylor list $1-\frac{x^2}{6}+\frac{x^4}{120}-\cdots$ — and demands they agree. }
  EXPLAIN_ENGINEER { $[x^m]$ is a probe: it samples one coefficient out of a series, ignoring the rest. Engineers do this constantly (impulse responses, $Z$-transforms). Here we probe $[x^{2k}]$ on both faces of $\frac{\sin x}{x}$ — the \stain{product}{product face} and the Taylor face — and set the readings equal. }

ROBOT: 4
  NAME { Elementary Symmetric Polynomials }
  EXPLAIN_MATHEMATICIAN { When you expand $\prod_k(1-c_k x^2)$ with $c_k=\tfrac{1}{k^2\pi^2}$, the coefficient of $x^{2j}$ is $(-1)^j$ times the \stain{esp}{elementary symmetric polynomial} $e_j(c_1,c_2,\dots)$: $e_1=\sum c_k$, $e_2=\sum_{i<j}c_ic_j$, etc. Hence $[x^{2k}]\stain{product}{\tfrac{S_n(x)}{x}}=(-1)^k\,\stain{esp}{e_k}$. The coefficients of the \stain{product}{root product} ARE the symmetric functions of the roots. }
  EXPLAIN_PHYSICIST { Multiply out $(1-c_1x^2)(1-c_2x^2)\cdots$ and the coefficient of each power is a tidy symmetric sum of the $c_k$. The first, $\thread{t2}{e_1=c_1+c_2+\cdots}$; the second, $\thread{t3}{e_2=\sum_{i<j}c_ic_j}$. These \stain{esp}{elementary symmetric polynomials} are precisely the coefficients $[x^{2k}]$ we just learned to read. }
  EXPLAIN_BIOLOGIST { Multiply several brackets like $(1-c_1x^2)(1-c_2x^2)$. The $x^2$ coefficient is $\thread{t2}{c_1+c_2+\cdots}$ (pick one); the $x^4$ coefficient is $\thread{t3}{\text{all the pairs } c_ic_j}$ (pick two). These "pick-$k$-and-multiply" sums are the \stain{esp}{elementary symmetric polynomials} — the natural language of a product. }
  EXPLAIN_ENGINEER { If you know a system's poles, its characteristic polynomial's coefficients are the \stain{esp}{elementary symmetric polynomials} of those poles: sum of poles, sum of pairwise products, and so on. Same structure here: the \stain{product}{sine product's} coefficients $[x^{2k}]=(-1)^k\stain{esp}{e_k}$ are symmetric functions of the inverse-square roots. }

ROBOT: 5
  NAME { Power Sums to Zeta }
  EXPLAIN_MATHEMATICIAN { The \stain{zeta}{power sums} of the $c_k=\tfrac1{k^2\pi^2}$ are $\thread{t4}{p_j=\sum_k c_k^{\,j}=\frac{1}{\pi^{2j}}\sum_k\frac{1}{k^{2j}}=\frac{H_n^{(2j)}}{\pi^{2j}}}$, and as $n\to\infty$, $\thread{t4}{H_n^{(2j)}\to \stain{zeta}{\zeta(2j)}}$. So $p_j\to \stain{zeta}{\zeta(2j)}/\pi^{2j}$. The analytic content of the whole construction is carried entirely by these power sums converging to zeta. }
  EXPLAIN_PHYSICIST { Besides "pick $k$ and multiply," there is "raise each to the $j$ and add": the \stain{zeta}{power sum} $\thread{t4}{p_j=\sum_k c_k^j}$. With $c_k=1/k^2\pi^2$ this is $\frac1{\pi^{2j}}\sum 1/k^{2j}$ — and that sum is exactly $\stain{zeta}{\zeta(2j)}$ in the limit. The zeta values enter as power sums. }
  EXPLAIN_BIOLOGIST { There is a second natural way to combine the $c_k$: don't pick pairs, just \stain{zeta}{raise each to a power and add them all}: $\thread{t4}{c_1^j+c_2^j+\cdots}$. For our numbers that sum is $\frac1{\pi^{2j}}(1+\frac1{2^{2j}}+\frac1{3^{2j}}+\cdots)$ — and the bracket is the very \stain{zeta}{zeta value} $\zeta(2j)$ we want. }
  EXPLAIN_ENGINEER { Power sums $\thread{t4}{p_j=\sum c_k^j}$ are like the traces of matrix powers — easy to compute, additive. Here each $p_j$ is a scaled \stain{zeta}{zeta value}: $p_j=\stain{zeta}{\zeta(2j)}/\pi^{2j}$ in the limit. So the data we can actually accumulate (power sums) are the zeta constants in disguise. }

ROBOT: 6
  NAME { Isaac Newton }
  EXPLAIN_MATHEMATICIAN { \stain{newton}{Newton's identities} link the two families: $\stain{newton}{(-1)^k k\,\stain{esp}{e_k}=\sum_{j=1}^{k}(-1)^{k-j-1}\stain{zeta}{p_j}\,\stain{esp}{e_{k-j}}}$. Combined with the product they give $[x^4]\tfrac{S_n}{x}=\tfrac{1}{2\pi^4}((H_n^{(2)})^2-H_n^{(4)})$, etc. Cleanly bundled, the limit reads $\displaystyle \stain{closed}{\zeta(2k)=[x^{2k}]\tfrac12\bigl(1-\pi x\cot(\pi x)\bigr)}$ — the cotangent generating function delivering every even zeta. }
  EXPLAIN_PHYSICIST { \stain{newton}{Newton's identities} are the dictionary between "pick-and-multiply" (the $\stain{esp}{e_k}$) and "power-and-add" (the $\stain{zeta}{p_j}$): $\stain{newton}{k e_k=\sum_j(-1)^{j-1}e_{k-j}p_j}$. Feeding our product through it collapses everything into one \stain{closed}{generating function}, $\stain{closed}{\pi x\cot\pi x=1-2\sum_{k\ge1}\zeta(2k)x^{2k}}$, whose coefficients are the zeta values. }
  EXPLAIN_BIOLOGIST { We now have two ways to mix the roots — pick-and-multiply ($\stain{esp}{e_k}$) and power-and-add ($\stain{zeta}{p_j}$). \stain{newton}{Newton's identities} are the exchange rate between them. Turn that crank on the sine product and all the even \stain{zeta}{zeta sums} fall out of one neat formula built from \stain{closed}{$\pi x\cot(\pi x)$}. }
  EXPLAIN_ENGINEER { \stain{newton}{Newton's identities} convert symmetric-coefficient data into power-sum data and back — a triangular, recursive solve. Apply it once and the bookkeeping collapses to a single \stain{closed}{generating function}: $\stain{closed}{\zeta(2k)=[x^{2k}]\tfrac12(1-\pi x\cot\pi x)}$. One cotangent expansion, all even zetas, no recursion needed downstream. }

ROBOT: 7
  NAME { Ferdinand von Lindemann }
  EXPLAIN_MATHEMATICIAN { Since each $\stain{evenzeta}{\zeta(2k)}$ is a \stain{closed}{rational multiple of $\pi^{2k}$}, and Lindemann (1882) proved $\pi$ — hence every $\pi^{2k}$ — transcendental, it follows that $\stain{evenzeta}{\zeta(2k)}$ is transcendental for all $k\ge1$. By stark contrast the odd values $\zeta(3),\zeta(5),\dots$ resist: only $\zeta(3)$'s irrationality (Apéry) is known. }
  EXPLAIN_PHYSICIST { A transcendental number is no root of any integer polynomial. Lindemann showed $\pi$ is one — that is why you cannot square the circle. Any \stain{closed}{rational $\times\,\pi^{2k}$} inherits this, so every \stain{evenzeta}{even zeta} is transcendental. The odd zetas have no such product formula, and remain almost completely mysterious. }
  EXPLAIN_BIOLOGIST { Some numbers can never be pinned down by a polynomial with whole-number coefficients — they are "transcendental." Lindemann proved $\pi$ is one of them. Because every \stain{evenzeta}{even zeta} equals a \stain{closed}{fraction times a power of $\pi$}, they are all transcendental too. The odd ones? We barely know anything — even $\zeta(3)$ took until 1979 to prove merely irrational. }
  EXPLAIN_ENGINEER { Practical upshot: $\stain{evenzeta}{\zeta(2k)}$ values are "exact" symbols — clean multiples of $\pi^{2k}$ you can carry through formulas without numerical drift, and provably not expressible as algebraic roots. The odd zetas lack this structure, so in applications they stay stubbornly numerical rather than closed-form. }
