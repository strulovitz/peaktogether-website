ROBOT: 2

BRIEFING_HINT { De Moivre's formula turns a complex power into a single multiplied
          angle, giving $(\cot x + i)^n$. This sentinel yields to its namesake. }
PROBLEM { Powering $\cos x + i\sin x$ to the $n$th multiplies the angle to $nx$,

EXPLAIN_MATHEMATICIAN { De Moivre's formula $(\cos x + i\sin x)^n = \cos nx + i\sin nx$
          lets Cauchy write $\frac{\cos nx + i\sin nx}{\sin^n x} = (\cot x + i)^n$;
          choosing $n = 2m+1$ odd later forces a clean polynomial in $\cot^2 x$. }
EXPLAIN_PHYSICIST { De Moivre's rule turns a power of $(\cos x + i\sin x)$ into the
          single angle $nx$. Dividing by $\sin^n x$ recasts it as $(\cot x + i)^n$ --
          the compact object whose imaginary part carries everything. }
EXPLAIN_BIOLOGIST { A beautiful shortcut: raising $\cos x + i\sin x$ to the $n$th power
          just multiplies the angle to $nx$. Rewriting that gives the tidy expression
          $(\cot x + i)^n$, the seed of the whole proof. }
EXPLAIN_ENGINEER { De Moivre's formula is the rotation rule for complex numbers:
          powering rotates the angle $n$-fold. Cauchy repackages it as $(\cot x + i)^n$,
          ready to be expanded and split into real and imaginary parts. }

EXPLAIN_MATHEMATICIAN { Binomial-expanding $(\cot x + i)^n$ and taking imaginary parts
          gives, with $n = 2m+1$, $\frac{\sin(nx)}{\sin^n x} = \binom{n}{1}\cot^{n-1}x

EXPLAIN_PHYSICIST { Expand $(\cot x + i)^n$ by the binomial theorem; powers of $i$ sort
          the terms into real and imaginary parts. The imaginary part is

          $\sin(nx)/\sin^n x$. }
EXPLAIN_BIOLOGIST { The binomial theorem multiplies out $(\cot x + i)^n$ into many
          terms. Because $i^2 = -1$, they alternate in sign and split into two groups;
          one group is the cotangent polynomial Cauchy needs. }
EXPLAIN_ENGINEER { The binomial theorem is the expansion engine: it turns

          coefficients: $\sum_{r=1}^{m} \cot^2 x_r = \frac{2m(2m-1)}{6}$. }

PROBLEM { As $m \to \infty$ both bounds tend to $\frac{\pi^2}{6}$, pinning the sum
          there. Who put this squeeze on a rigorous, modern footing? }
EXPLAIN_MATHEMATICIAN { Summing the inequality and multiplying by
          $\left(\frac{\pi}{2m+1}\right)^2$ gives $\frac{\pi^2}{6} \frac{2m}{2m+1}
          \frac{2m-1}{2m+1} < \sum_{k=1}^{m} \frac{1}{k^2} < \frac{\pi^2}{6}
          \frac{2m}{2m+1} \frac{2m+2}{2m+1}$. As $m \to \infty$ both bounds tend to
          $\frac{\pi^2}{6}$, so by the squeeze theorem $\sum_{k=1}^{\infty}
          \frac{1}{k^2} = \frac{\pi^2}{6}$. }

          so the trapped sum has nowhere else to go. }
EXPLAIN_ENGINEER { The squeeze theorem is the closing move: bound below and above by
          sequences with a common limit, and the middle inherits it. Both bounds tend
          to $\frac{\pi^2}{6}$, fixing the Basel sum exactly. }
