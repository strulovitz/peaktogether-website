PROBLEM { A sum of positive decreasing terms converges iff its matching integral is

EXPLAIN_MATHEMATICIAN { The integral test (Maclaurin-Cauchy): for $f$ positive and

          = -\frac{1}{x} \rvert_1^{\infty} = 1 < \infty$, so $\sum 1/n^2$ converges. }
EXPLAIN_PHYSICIST { Lay the bars $f(n)$ beside the smooth curve $f(x) = 1/x^2$.

          $\int_{1}^{\infty} \frac{1}{x^2} \, dx = 1$ is a finite area, so the sum is
          finite too. }
EXPLAIN_BIOLOGIST { Picture each term as a thin rectangle and the smooth curve

          sequence converges, so the limit exists and lies in $(0, 2)$. }
EXPLAIN_PHYSICIST { Stack the two facts. The sum is below $1 + \left( 1 - \frac{1}{N}
          \right)$, which rises to $2$. And every term $1/n^2$ is positive, so the
          partial sums only increase. An increasing quantity that can never pass the
          ceiling $2$ must approach a definite limit -- it is squeezed into the
          interval $(0, 2)$. }
EXPLAIN_BIOLOGIST { Two facts together finish the job. First, the running total can
          never climb above $2$. Second, since every piece you add is positive, the

          truly converges. }

BRIEFING_HINT { The closed form via Bernoulli numbers: a master formula turns the

          \frac{(2\pi)^{2n} (-1)^{n+1} B_{2n}}{2 (2n)!}$, where $B_{2n}$ is a Bernoulli

          \frac{(2\pi)^2 \cdot \frac{1}{6}}{2 \cdot 2!} = \frac{\pi^2}{6}$ -- Basel as
          the first case of a whole family. }
EXPLAIN_PHYSICIST { The Bernoulli numbers $B_2 = \frac{1}{6}, B_4 = -\frac{1}{30},
          \dots$ are a fixed sequence of rationals. Plug $n = 1$ into $\zeta(2n) =
          \frac{(2\pi)^{2n} \lvert B_{2n} \rvert}{2 (2n)!}$: numerator $(2\pi)^2 \cdot \frac{1}{6}
          = \frac{4\pi^2}{6}$, denominator $2 \cdot 2 = 4$, giving $\frac{4\pi^2}{24}
          = \frac{\pi^2}{6}$. The same formula at $n = 2$ delivers $\zeta(4) =
          \frac{\pi^4}{90}$. }
