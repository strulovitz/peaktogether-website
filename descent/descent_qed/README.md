# Descent QED — Step 1.2: The Empty Mine

Fly through Corridor EULER-1734 — a descending mine shaft with chevron-framed
robot stations. Colliding camera, ELBOW bend, distance-sorted translucency.

## Run

```
python main.py
```

## Keys

| Key | Action |
|-----|--------|
| W/A/S/D | Move |
| R/F | Up / Down |
| Arrow keys | Look |
| [ / ] | Wall transparency (0 = automap wireframe, 0.9 = solid rock) |
| F3 | Wireframe toggle |
| Esc | Quit |

## Requirements

```
pip install pygame PyOpenGL numpy
```
