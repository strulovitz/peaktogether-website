You remember this.

In 1996, Quake gave you a true 3D world — dark stone chambers, echoing halls, and a demon waiting in the shadows. We kept that feeling — the torch-lit rooms, the hidden doors, the creature stirring in the dark — and poured something completely new inside.

Here's what's different — and amazing.

This isn't a shooter. Every room is a proposition from Newton's Principia — the 1687 book that invented physics. The rooms are connected as a concept-graph dungeon: each door teleports you straight into the next idea, and a corner minimap shows you the force-directed graph — every room a dot, every logical link a line, generated automatically from the book's actual concepts.

Walls carry the step-by-step geometric proof. Each step is a drawing panel (a real Asymptote figure) beside a full-LaTeX text panel. You "read" a panel by shooting it — it glows from black-and-white to colored, with the matching words and shapes lit in the same colors so the picture and the sentence teach each other. Light up every panel and the final proof-wall becomes a hidden door. Shoot it, and the room's one demon emerges. Kill it, and the ceiling equations bleed red — the room is cleared, and you've earned the insight.

Get it wrong? Nothing bad happens. There's no health bar, no lives, no game-over — the challenge is understanding, not survival. You're not being tested; you're being shown.

🏔️ The mountain you're climbing

The peak: Newton's Principia Mathematica — the 1687 book that gave us the laws of motion, universal gravitation, and the mathematical framework for classical physics. Every proposition builds on earlier ones in a strict logical chain, which maps perfectly to a graph of rooms and corridors. This first level walks Book I, Sections I–III — Newton's "first and last ratios" leading toward the inverse-square law.

The Motte English translation is our source. Each figure from the book is rebuilt in Asymptote (a modern LaTeX geometry tool), with per-step highlighting so you can watch a geometric proof unfold one construction at a time — faithful to the printed page, never a simplification.

What you'll actually understand by the end:

  • How Newton reasoned with vanishing quantities — calculus, before calculus had a name.
  • Why arcs, chords, and tangents become equal "in the last ratio."
  • How geometric reasoning (not algebra!) built the foundations of physics.
  • What "fidelity to the printed page" means — we reproduce the real proof.

❤️ How you two play

Quake: Principia is built for two people on one screen — a co-op design that gives each player a real, distinct job. (Playing solo works too — one person can do both.)

🕹️ Player 1 — The Mover

Owns the body and heading. Walks the 3D dungeon and decides where to go, stepping through doorways into each new proposition. Plays on keyboard — or, if you have one, a Thrustmaster T.16000M flight stick.

🎯 Player 2 — The Aimer

Owns the reticle. Aims freely, reads the panels, shoots them to light them up, opens the hidden proof-wall, and fights the room's single demon. Plays on mouse — or an Xbox controller. The Aimer's aim never yanks the camera around, so there's zero couch-co-op fighting over the view.

🎮 Controls

Keyboard + mouse is all you need. A flight joystick and an Xbox controller are optional — not required, just more fun — and they work at the same time as the keyboard and mouse.

⌨️ Keyboard + Mouse

  • W A S D — move & strafe
  • Mouse — look around and aim the reticle
  • Left-click — shoot a panel (colors it) / shoot the hidden door / shoot the demon
  • R — read a panel up close (toggle)
  • Esc — quit

🕹️ Optional controllers (not required — just more fun)

A quick ~1-second calibration runs at startup for the joystick — just keep the stick centered for a moment.

Thrustmaster T.16000M flight stick → the Mover:

  • Move the stick — walk & strafe.
  • Twist the stick — turn left / right.
  • Throttle slider — run forward / backward (push forward to run ahead, pull back to reverse; centered = stop).

Xbox controller → the Aimer:

  • Right stick — look around & aim the reticle.
  • Right trigger or A — shoot.

🛡️ God-mode — you cannot die

There is no health bar. No lives. No game-over screen. Infinite ammo, one demon per room (hidden behind the final proof-wall), no level boss. You're here to learn Newton's Principia, not to grind.

⚙️ The tech

Language: pure Python (Windows-first). Graphics: moderngl + pyglet (a direct OpenGL pipeline — no engine hiding the work, our own GLSL shaders). Math: NumPy, NetworkX, Pydantic v2. Build pipeline: Asymptote (geometry figures), Matplotlib, LaTeX, PyInstaller (packaging). Every commit is on GitHub — we build in public.

⬇️ Download & play (Windows)

The easy way — no Python, no terminal, no installer:

▶ Play on Windows — Free Mirror (GitHub)
  1. Download the Windows .zip.
  2. Right-click it → Extract All…
  3. Open the extracted folder.
  4. Double-click “Quake Principia.exe” — that's it! 🎉
  5. Grab your partner — and a flight joystick + Xbox controller if you have them. 🎮

To uninstall, just delete the folder. It installs nothing and never touches your system.

🛡️ Heads-up: we're a brand-new, free, open-source project, so Windows may say “Unknown publisher.” That's expected for small free games — click “More info” → “Run anyway.” The game needs no admin permission, installs nothing, and doesn't touch your Python or system. Source code.

🧑‍💻 Prefer to run from source? (for developers)

  1. Get the code from GitHub (free, open-source — no account, no payment, ever).
  2. Make sure you have Python installed.
  3. Install the libraries: pip install moderngl pyglet numpy pillow pydantic networkx
  4. Run it: cd quake then python app.py
